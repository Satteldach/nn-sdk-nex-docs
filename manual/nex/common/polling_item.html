6. Required and Recommended Periodic Checks

There are various items in NEX that need to be checked periodically, and various items that Nintendo recommends checking periodically.

6.1. Game Server Connectivity Check

After logging in to the game server successfully with the NgsFacade::Login() function, you can check for connectivity with the game server using the NgsFacade::IsConnected() function. NEX detects network disconnections as server disconnections.

A disconnection from the server will end the availability for NEX server services. Check server connectivity when it is appropriate to do so within your game specifications. Display an error when a disconnection is detected, and call NgsFacade::Logout() to destroy NgsFacade.

By setting Core::GetInstance()->SetTerminateImmediately(true) before calling NgsFacade::Logout(), the overall finalization process becomes faster by not completing the standard disconnect process. This is an irregular termination when there is a network communication error. Do not use it in a standard finalization sequence.

For more information, see the API reference.
