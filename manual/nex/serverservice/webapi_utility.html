11.7. Utilities

11.7.1. General Information

Module name utility
API version 1

11.7.2. Managing Application Settings

11.7.2.1. Getting Setting Indices

GET /nex/utility/v1/application_setting/setting_index/integer

Gets the indices for settings to which an integer value has been assigned.

Request Example:

GET /nex/utility/v1/application_setting/setting_index/integer HTTP/1.1

Response Example:

HTTP/1.1 200 OK
Content-Type:  text/xml;charset=utf-8

<? xml version="1.0" encoding="UTF-8"? >
<nex>
  <utility>
    <setting_indexes length="2">
      <setting_index>0</setting_index>
      <setting_index>1</setting_index>
    </setting_indexes>
  </utility>
</nex>

11.7.2.2. Getting the Value for a Specified Setting Index

GET /nex/utility/v1/application_setting/integer/(setting_index)

Gets the integer value set to the specified setting index.

Request Example:

GET /nex/utility/v1/application_setting/integer/0 HTTP/1.1

Response Example:

HTTP/1.1 200 OK
Content-Type:  text/xml;charset=utf-8

<? xml version="1.0" encoding="UTF-8"? >
<nex>
  <utility>
    <settings length="2">
      <setting>
        <setting_index>0</setting_index>
        <value>10</value>
        <key>0</key>
        <description>desc-00</description>
      </setting>
      <setting>
        <setting_index>0</setting_index>
        <value>20</value>
        <key>1</key>
        <description>desc-01</description>
      </setting>
    </settings>
  </utility>
</nex>

11.7.2.4. Adding a Setting Value

PUT /nex/utility/v1/application_setting/integer
POST /nex/utility/v1/application_setting/integer/put

Sets an integer value to a setting. If a value has already been set to the specified setting index and key, that value is overwritten.

Request Body:

Element Parent Elements Description
change   Root element. Required.
param change Specifies the data to add. More than one can be specified. Required.
setting_index param Setting index. Required.
key param Key. Required.
value param Value. Required.
description param Description. Required.

Request Example:

PUT /nex/utility/v1/application_setting/integer HTTP/1.1

<change>
  <param>
    <setting_index>0</setting_index>
    <key>0</key>
    <value>10</value>
    <description>desc-00</description>
  </param>
  <param>
    <setting_index>0</setting_index>
    <key>1</key>
    <value>20</value>
    <description>desc-01</description>
  </param>
  <param>
    <setting_index>1</setting_index>
    <key>0</key>
    <value>-1</value>
    <description>desc-01</description>
  </param>
</change>

Response Example:

HTTP/1.1 200 OK
Content-Type:  text/xml;charset=utf-8

<? xml version="1.0" encoding="UTF-8"? >
<nex>
  <utility>
    <settings>
      <changed length="3"/>
    </settings>
  </utility>
</nex>

length is the number of settings that were added.

11.7.2.5. Deleting the Value Set to a Setting Index

POST /nex/utility/v1/application_setting/integer/(setting_index)/delete

Deletes the integer value set to the specified setting index.

Request Body:

Element Parent Elements Description
delete   Root element. Required.
param change Specifies the data to add. More than one can be specified. Required.
key param Key. Required.

If a key is specified in the request body, only the integer values associated with that key are deleted. If the request body is empty, all integer values set to the specified setting index are deleted.

Request Example:

POST /nex/utility/v1/application_setting/integer/0/delete HTTP/1.1

<delete>
  <param>
    <key>0</key>
  </param>
  <param>
    <key>1</key>
  </param>
</delete>

Response Example:

HTTP/1.1 200 OK

<? xml version="1.0" encoding="UTF-8"? >
<nex>
  <utility>
    <settings>
      <deleted length="2"/>
    </settings>
  </utility>
</nex>

11.7.2.7. Clearing and Resetting an Existing Value for the Specified Setting Index

POST /nex/utility/v1/application_setting/integer/(setting_index)/replace

Clears the existing integer value set to the specified setting index and then sets the new value to that setting index.

Request Body:

Element Parent Elements Description
change   Root element. Required.
param change Specifies the data to add. More than one can be specified. Required.
setting_index param Setting index. If the setting index specified here is different than the one specified in the URL, an error is returned. If left unspecified, the setting index in the URL is used.
key param Key. Required.
value param Value. Required.
description param Description. Required.

Request Example:

POST /nex/utility/v1/application_setting/integer/0/replace HTTP/1.1

<change>
  <param>
    <setting_index>0</setting_index>
    <key>0</key>
    <value>-1</value>
    <description>desc-00</description>
  </param>
</change>

Response Example:

HTTP/1.1 200 OK
Content-Type:  text/xml;charset=utf-8

<? xml version="1.0" encoding="UTF-8"? >
<nex>
  <utility>
    <settings>
      <deleted length="2"/>
      <set length="1"/>
    </settings>
  </utility>
</nex>

deleted is the number of settings that were cleared. length is the number of settings that were configured.
