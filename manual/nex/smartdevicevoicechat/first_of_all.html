1. Introduction

This document describes how to use the Nintendo Switch Online Voice Chat features of NintendoSDK-NEX (the NintendoSDK Network Extension (NEX)).

The Nintendo Switch Online Voice Chat feature provides functionality linked to the Nintendo Switch Online app for voice chat on smart devices.

An application to OMAS that is separate from the NEX game server must be completed for development using this feature. The Nintendo Switch Online app for developers is also necessary to check the behavior of this feature in the development environment. The procedures that are necessary for development are described in the Nintendo Switch Online Voice Chat Guide. Refer to the Nintendo Switch Online Voice Chat Guide along with this document when implementing this feature.
