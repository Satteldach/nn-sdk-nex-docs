3. Glossary

Table 3.1. Nintendo Switch Online Voice Chat Glossary
Glossary Description
Nintendo Switch Online App A smart device application providing services that are linked to Nintendo Switch software.
Matchmaking Voice Chat A feature for voice chat between users who are gathered in matchmaking for online battles in NX applications.
Voice Chat Server The server that provides the Matchmaking Voice Chat feature. It exists separately from the NEX game server.
Room A location existing on the Voice Chat Server to gather users. You can voice chat among members participating in the room.
Channel A group that voice chats together in the same room. Even if you are participating in the same room, voice chat sound data is not sent when the channels differ.
