Sample Demo List

Sample demos for NintendoSDK NEX are in the following location.

  • $NINTENDO_SDK_NEX_ROOT/Samples/Applications/NEX/

The following table describes each demo.

Sample Demo List
Name Description
01-Basic/CallContextBasic Shows the basic operations of the CallContext class.
01-Basic/CallContextAdvanced This sample demo describes more advanced methods of using the CallContext class.
01-Basic/ThreadMode This sample demo is for learning the differences between thread modes.
02-Login/NnSdkLogin This sample demo describes how to log in to NGS.
02-Login/NnSdkMultiLogin This sample demo uses multiple accounts to log in to NGS.
03-Rmc This sample demo issues an RMC (remote method call) to NGS.
04-Matchmaking/AutoMmMessaging This sample demo uses auto-matchmaking and messaging to communicate. It is implemented asynchronously.
04-Matchmaking/AutoMmMessagingEasy This sample demo uses auto-matchmaking and messaging to communicate.
04-Matchmaking/CreateAndBrowse This sample demo creates and searches for matchmaking sessions.
04-Matchmaking/MatchmakeReferee This sample demo uses MatchmakeReferee to fairly records battle results.
04-Matchmaking/PersistentGathering This sample demo uses persistent gathering to perform matchmaking within a specific group.
04-Matchmaking/TeamMatchmake This sample demo creates teams and performs matchmaking.
05-Ranking This sample demo uses ranking.
06-Ranking2 This sample demo uses ranking 2.
07-DataStore This sample demo uses data store.
08-Subscriber This sample demo uses subscriber.
09-Debug This sample demo uses the debugging support features to record a history of server API calls.
10-VSocket This sample demo shows how to use VSocket to enable use of NEX and a third party peer-to-peer network at the same time.
Others/MatchmakeVoiceChat This sample demo uses Matchmaking Voice Chat. To use this sample demo, you must use the Nintendo Switch Online app for developers.
common/NexDemoUtil The utility codes used in the sample demos are included. They can be incorporated into the application as is, or be edited first. The descriptions of each function are noted in the header.

An Internet connection is required in order to run each sample demo, with some exceptions. Before executing the sample demo, use features such as system settings to verify that the Internet connection settings have been configured.

A network service account is required in order to run the various sample demos. Before running these sample demos, use a method such as DevMenu to link a network service account to the user account.

The Nintendo Switch Online policy for the application specified in the sample demos (the application ID) is No features require membership. As a result, you do not need a Nintendo Switch Online membership to run these sample demos. For more information about the Nintendo Switch Online policies, see the Nintendo Switch Online Play Guide.
