void nn::nex::SubscriberGetContentParam::SetSize ( uint32_t  size_)

Sets the maximum number of pieces of content to get.

The default value is 20. Up to SubscriberConstants::MAX_TOPIC_CONTENT_SIZE pieces of content can be stored in a single topic. As a result, only SubscriberConstants::MAX_TOPIC_CONTENT_SIZE pieces of content will be retrieved even if you specify a value larger than SubscriberConstants::MAX_TOPIC_CONTENT_SIZE. Set a value of no more than 20 when polling with the SubscriberClient::GetContent() function.

void nn::nex::SubscriberGetContentParam::SetMinimumContentId ( uint64_t  minimumContentId_)

Sets a minimum content ID for limiting how much content to get.

Only content items with an ID larger than the value of minimumContentId are retrieved. Content whose ID matches minimumContentId is not included. When polling with the SubscriberClient::GetContent() function, remember which was the largest content ID among the content that was retrieved the last time, and specify that value for the parameter so the same content is not retrieved again. The default value is 0.
