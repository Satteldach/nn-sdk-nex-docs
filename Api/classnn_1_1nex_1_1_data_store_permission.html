void nn::nex::DataStorePermission::SetRecipientIds ( const qVector< PrincipalID > &  recipientIds_)

Specifies the users who have permission.

Specifies the principal IDs of users who have permission. The specified values can be used only when DataStoreConstants::PERMISSION_SPECIFIED or DataStoreConstants::PERMISSION_SPECIFIED_FRIEND are specified by using the DataStorePermission::SetPermission function. When DataStoreConstants::PERMISSION_SPECIFIED is specified, only people who have a principal ID specified by this function have permission. When DataStoreConstants::PERMISSION_SPECIFIED_FRIEND is specified, only people who have a principal ID specified by this function, and who are also a friend at the time of access, have permission. If the list size exceeds DataStoreConstants::MAX_PID_LIST_SIZE, the results of DataStoreClient::PostObject() and DataStoreClient::ChangeMeta() will be QERROR(DataStore, InvalidArgument).

const qVector<PrincipalID>& nn::nex::DataStorePermission::GetRecipientIds ( ) const

Gets the users who have permission.

Returns
The list of principal IDs of persons who have permission.

If the data was searched using the DataStoreClient::SearchObject() or DataStoreClient::SearchObjectLight() function, the principal IDs of users with access permission (DataStoreMetaInfo::GetAccessPermission) and update permission (DataStoreMetaInfo::GetUpdatePermission) in the search result record are not returned and this list is always empty. If the data was obtained using the DataStoreClient::GetMeta() function, this function stores valid values.
