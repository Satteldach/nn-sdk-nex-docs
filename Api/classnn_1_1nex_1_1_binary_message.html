Detailed Description

Class that stores binary data.

To use instant messaging features, use either this class, the UserMessage class, or the TextMessage class.

static Data* nn::nex::Data::DynamicCast ( Data *  pData)
staticinherited

Performs a dynamic cast for the Data class pointer.

This function automatically creates a class derived from the Data class defined with DDL by the DDL compiler.

By calling same-name functions defined by each class, the pointer specified by the argument is dynamically cast to the pointer of each class type. With the UserMessage::DynamicCast function, for example, the Data*-type pointer specified by the argument is dynamically cast to UserMessage*. If casting is possible, a valid pointer is returned; if casting is not possible, NULL is returned.

Dynamic casting is independently implemented with this function, so it is not necessary to enable RTTI.

Parameters
[in]pDataSpecifies a pointer to the class derived from the Data class.
Returns
Returns the pointer specified with pData as a pointer to a class when calling.
Return Values
NULL Indicates that the pointer specified by pData is not a class derived from the class that was called. For example, when UserMessage::DynamicCast is called, NULL is returned if the pData entity is not a UserMessage-derived class.
