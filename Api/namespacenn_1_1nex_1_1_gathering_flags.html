enum nn::nex::GatheringFlags::GatheringFlags

Enumerated type that defines the characteristics of a gathering registered on the game server.

Enumerated type that defines the characteristics of a gathering registered on the game server. Set these flags for a gathering using the Gathering::SetFlag() function. This bit flag allows multiple flags to be specified.

MigrateOwner 

If this flag has been specified and if the current owner of the gathering leaves the matchmaking session, the game server selects a new owner for the gathering from among the participants. If no participants can become the new owner, the gathering is deleted. If you plan to change the owner at arbitrary times, use the MatchmakeExtensionClient::MigrateGatheringOwnership() function.

NoPersistentParticipation 

When this flag is specified, leaves the persistent gathering because of logging out or disconnection from the game server.

This flag is only effective for persistent gatherings.

AllowNoParticipant 

When this flag is specified, the persistent gathering is not deleted even if there are zero participants. Registration of participants other than those of the client application registered on the server side is suppressed. For example, with official persistent gatherings, even if all client applications leave, a participant with a fixed principal ID, provided by the server-side, is registered so that the persistent gathering is not deleted. When this flag is specified, registration of participants not of this type of client application is unnecessary, so they are suppressed.

When this flag is specified, to delete a gathering you must explicitly call MatchMakingClient::UnregisterGathering().

This flag can only be specified for persistent gatherings.

ChangeOwnerByOtherHost 

This flag sets whether ownership of the matchmaking session can be taken from other participants by calling the MatchMakingClient::UpdateSessionHost() or MatchMakingClient::UpdateGatheringOwnership() function.

This option is enabled by default for NEX 3.7 and later versions.

See also
MatchMakingClient::UpdateSessionHost(), MatchMakingClient::UpdateGatheringOwnership()
NotifyParticipationEventsToAllParticipants 

ParticipationEvents::Participate, ParticipationEvents::Disconnect, and ParticipationEvents::EndParticipation notifications are sent to all participants for matchmaking sessions, including the local host.

When NotifyParticipationEventsToAllParticipantsReproducibly is simultaneously specified, NotifyParticipationEventsToAllParticipantsReproducibly takes priority.

NotifyParticipationEventsToAllParticipantsReproducibly 

ParticipationEvents::Participate, ParticipationEvents::Disconnect, and ParticipationEvents::EndParticipation notifications are sent to all participants for matchmaking sessions, including the local host. In addition, when a user joins the matchmaking session, a ParticipationEvents::Participate notification to all existing users is sent for the new user.

When NotifyParticipationEventsToAllParticipants is simultaneously specified, NotifyParticipationEventsToAllParticipantsReproducibly takes priority.
