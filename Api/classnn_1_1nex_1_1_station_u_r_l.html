Detailed Description

Constructs Station URLs.

This class constructs a URL for a particular node. StationURL requires a minimum of one URL, one port, and a ConnectionID for NAT traversal.

Flags
Enumerators
BehindNAT 

The station corresponding to StationURL is under a NAT device.

Public 

StationURL refers to a public IP address and port number.

DetectedByNatCheck 

StationURL refers to the global address detected by the NAT check server. The public flag will always be raised at the same time.

DetectedByNgs 

StationURL refers to the global address detected by NGS. The public flag will always be raised at the same time.
