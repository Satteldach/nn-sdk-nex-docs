Detailed Description

Represents persistence settings.

Constructor & Destructor Documentation

nn::nex::DataStorePersistenceInitParam::DataStorePersistenceInitParam ( uint16_t  persistenceSlotId = DataStoreConstants::INVALID_PERSISTENCE_SLOT_ID,
bool  deleteLastObject = true 
)
explicit

Constructor.

If you are going to perpetuate the data, specify a persistence slot ID. If you specify DataStoreConstants::INVALID_PERSISTENCE_SLOT_ID, which is the default parameter, the data is not perpetuated. The parameter in deleteLastObject specifies whether to delete any data that happens to already exist in the specified persistence slot ID.

Parameters
[in]persistenceSlotIdThe persistence slot ID.
[in]deleteLastObjectSpecifies whether to delete the previous data.

void nn::nex::DataStorePersistenceInitParam::SetPersistenceSlotId ( uint16_t  persistenceSlotId_)

Sets the persistence slot ID.

For the persistence slot ID, set 0 or any other value less than DataStoreConstants::NUM_PERSISTENCE_SLOT, or specify DataStoreConstants::INVALID_PERSISTENCE_SLOT_ID. If you specify DataStoreConstants::INVALID_PERSISTENCE_SLOT_ID, the data is not perpetuated.
