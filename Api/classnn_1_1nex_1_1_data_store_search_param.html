void nn::nex::DataStoreSearchParam::SetDestinationIds ( const qVector< PrincipalID > &  destinationIds_)

Sets the principal IDs of the access rights owners to search for.

When setting access privileges during data upload, the rights holder's principal ID can be set in the second argument of the DataStorePermission::DataStorePermission() function. If this function is used, you can search for data by specifying the rights holder's principal ID. If not specified, this condition is removed from search conditions. You can specify this if the search type is either DataStoreConstants::SEARCH_TYPE_PUBLIC or DataStoreConstants::SEARCH_TYPE_FRIEND. To include the local host's own access privileges in the search, set the search type to DataStoreConstants::SEARCH_TYPE_RECEIVED. When DataStoreConstants::SEARCH_TYPE_RECEIVED is used, you do not need to set the local host's own principal ID with this function. (However, an error will not occur if the local host's principal ID is specified.) It can be used to choose the access privilege holder as the send destination, and search for data that a specific person has received. If the list size exceeds DataStoreConstants::MAX_PID_LIST_SIZE, the results of DataStoreClient::SearchObject() and DataStoreClient::SearchObjectLight() will be QERROR(DataStore, InvalidArgument).

Parameters
[in]destinationIds_The list of principal IDs, specified as access privileges, to search for. When you specify several principal IDs, search is performed using OR.

void nn::nex::DataStoreSearchParam::SetCreatedAfter ( const DateTime &  createdAfter_)

Sets the starting point of the upload date and time to search for.

We do not recommend using this function because the upload date starting point will be deprecated as a search parameter.

A search is made for data updated after the date and time specified by the DataStoreSearchParam::SetCreatedAfter() function, but before the time specified by the DataStoreSearchParam::SetCreatedBefore() function. When DataStoreConstants::INVALID_DATE_TIME is specified, this condition is removed from search conditions. The default is DataStoreConstants::INVALID_DATE_TIME.

void nn::nex::DataStoreSearchParam::SetResultRange ( const ResultRange &  resultRange_)

Sets the search range.

The default is ResultRange(). The maximum number of search results to get that can be specified with this function is DataStoreConstants::MAX_SEARCH_RESULT_SIZE.

If you set RESULTRANGE_ANY_OFFSET, up to 1000 of the first search results, as arranged based on the sort target and the sort order, are treated as the target, and search result entries are taken in random order from that. In this case, the maximum number of search results that can be specified is DataStoreConstants::MAX_SEARCH_ANY_RESULT_SIZE.

void nn::nex::DataStoreSearchParam::SetTags ( const qVector< String > &  tags_)

Sets the tags to search for.

The default is qVector<String>(). Searches look for a match to all specified tags. You can specify as many tags as DataStoreConstants::NUM_TAG_SLOT allows. Empty string tags cannot be specified.

When a tag is specified, the data type to search for must be specified using the DataStoreSearchParam::SetDataType() function. When specifying tags, only one data type can be specified.

Tags cannot be set if you are using the DataStoreClient::SearchObjectLight() function.

void nn::nex::DataStoreSearchParam::SetUseCache ( const bool  useCache_)

Sets whether to use the search results cache.

To use the search results cache, the search type must be set to DataStoreConstants::SEARCH_TYPE_PUBLIC with the DataStoreSearchParam::SetSearchType() function, and the type of principal ID of the user that uploaded the content must be set to DataStoreConstants::SEARCH_TARGET_ANYBODY with the DataStoreSearchParam::SetOwnerType() function.

bool nn::nex::DataStoreSearchParam::GetTotalCountEnabled ( )

Gets whether to get the total number of matching hits to the search criteria.

The default value is false. When false, the total number of matching hits to the search criteria is always 0. (The search results contain the data that that was hit in the search.) When true, the search results include the total number of matching hits to the search criteria.
