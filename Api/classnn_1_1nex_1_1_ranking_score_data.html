void nn::nex::RankingScoreData::SetUpdateMode ( RankingConstants::UpdateMode  updateMode_)

Specifies the score update mode.

When RankingConstants::UPDATE_MODE_NORMAL (the default mode) is specified, the past scores uploaded in the category by the local host are maintained, and the score used for the rankings is the highest score within the specified time scope. When an identical highest score has been recorded multiple times within the specified time scope, the latest score is used for rankings.

If you specify RankingConstants::UPDATE_MODE_DELETE_OLD, the old score in the category is deleted before the new score is uploaded. The latest score is always used, regardless of whether it is better or worse.

[in]updateMode_The score update mode.
