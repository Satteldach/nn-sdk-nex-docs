Detailed Description

Critical section class.

This class guarantees that only one thread will run during the calls to the Enter() and Leave() functions. You can use the ScopedCS class to avoid accidentally permanently locking the CriticalSection object.

The CriticalSection class is enabled only when using a thread-safe thread mode. In thread-unsafe thread modes, the CriticalSection::Enter() function performs nothing.

Using the CriticalSection obtained from Scheduler::SystemLock() guarantees that NEX internal processing is paused, and that no system changes occur during that interval.

virtual void nn::nex::CriticalSection::Enter ( )
virtual

Enters a critical section.

The thread that calls this member function has ownership of the critical section until the call to Leave(). If another thread has already entered the critical section, this thread will block until that thread has left the critical section.

ScopedCS::ScopedCS
virtual bool nn::nex::CriticalSection::TryEnter ( )
virtual

Attempts to enter a critical section.

This thread will enter the critical section, as long as it is not owned by another thread. The thread that calls this member function has ownership of the critical section until the call to Leave(). If another thread has already entered the critical section, this function immediately returns false without entering it. This function always returns true in thread-unsafe mode.


Return Values

true: Entered the critical section.

false: Could not enter the critical section.

static void nn::nex::CriticalSection::SetEnableDetectRaceCondition ( bool  enable)
static

Enables or disables race condition checks.

This checks to see whether a Debug or Develop build of an application is calling NEX functions in parallel while the NEX library is in thread-unsafe mode. This function temporarily enables or disables that feature. It is extremely dangerous to disable this feature. You are only able to disable this feature for testing purposes.

Parameters
[in]enableSpecifying a value of true enables this feature; a value of false disables it.
