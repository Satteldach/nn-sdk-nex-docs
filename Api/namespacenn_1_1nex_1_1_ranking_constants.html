enum nn::nex::RankingConstants::UpdateMode

The score update mode that is specified when scores are uploaded.

Enumerators
UPDATE_MODE_NORMAL 

Records the score if it is better than the earlier score in that category.

UPDATE_MODE_DELETE_OLD 

Deletes the earlier score in the category and records the latest score. The latest score is always used, regardless of whether it is better or worse.

enum nn::nex::RankingConstants::OrderCalculation

Represents the rank calculation method.

Enumerators
ORDER_CALCULATION_113 

Same order when there are multiple ties. For example #1, #1, #3...

ORDER_CALCULATION_123 

If there are identical scores, rank them according to time of update (measured in seconds), ranking earlier scores higher. If they have the same update time, give a higher rank to the one with the smaller principal ID.

const uint32_t nn::nex::RankingConstants::MAX_RANGE_RANKING_ORDER = 1000
static

The maximum value for the order of the range of rankings that can be obtained within the range of rankings.

For more information about the maximum length of rankings that can be obtained with one operation, see the RankingOrderParam::SetLength() function.

const uint32_t nn::nex::RankingConstants::MAX_ACCURATE_ORDER = 5000
static

The highest value order for which ranking calculations can be performed accurately.

If the ranking obtained with the RankingClient::GetRanking() function (when nearby ranking or individual ranking data is obtained) or with the RankingClient::GetApproxOrder() function is smaller than this value, ranking calculations can be performed accurately in real time.
If the obtained ranking is larger than this maximum value, small calculation errors may occur because of when ranking data is obtained.
