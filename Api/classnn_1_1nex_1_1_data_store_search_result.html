uint32_t nn::nex::DataStoreSearchResult::GetTotalCount ( ) const

Gets the total count that match search conditions.

The meaning varies, depending on the DataStoreConstants::SearchResultTotalCountType value obtained by DataStoreSearchResult::GetTotalCountType.

Returns

const qVector<DataStoreMetaInfo>& nn::nex::DataStoreSearchResult::GetResult ( ) const

Gets the search results.

Returns
Returns a list of search results.

Currently, the principal IDs of persons who have permissions to access search result records (DataStoreMetaInfo::GetAccessPermission) and update search result records (DataStoreMetaInfo::GetUpdatePermission) are not returned and are always empty.
