Detailed Description

Statistical data on the round-trip time (RTT) to each device.

This class is stored in a StationProbeList where its data is updated when VSocket::ProbeStations() is called.

Member Function Documentation

uint32_t nn::nex::StationProbeList::PingStats::GetMin ( ) const

Returns the minimum round-trip time (RTT) measured to any device.

By default, the minimum round-trip time is Infinite. A return value of Infinite indicates that communications have not been established with any other devices.

Returns
The minimum round-trip time measured to any device. The unit is milliseconds.
