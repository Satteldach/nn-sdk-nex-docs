Detailed Description

This namespace defines error codes for the RendezVous module.

Enumeration Type Documentation

enum nn::nex::RendezVousErrorCode::ErrorCode

Error codes for the RendezVous module.

Enumerators
ConnectionFailure 

Connection could not be established, either with the rendezvous back end or a peer.

Failed to connect to the NGS.

NotAuthenticated 

The principal could not be authenticated by the Authentication Service.

The authentication process (starting from NGS authentication) is not complete.

InvalidUsername 

The principal tried to log in with an invalid user name, /that is,

/ The user name does not exist in the database. Invalid user name.

InvalidPassword 

The Principal either tried to log in with an invalid password for the provided user name or tried to join a Gathering with an invalid password.

Invalid password.

UsernameAlreadyExists 

The provided user name already exists in the database.

All user names must be unique. Identical user names have been added.

AccountDisabled 

The principal's account still exists in the database but the account has been disabled.

The account cannot be used.

AccountExpired 

The principal's account still exists in the database but the account has expired.

The account has expired.

ConcurrentLoginDenied 

The principal does not have the capabilities to perform concurrent logins, /that is,

/ at any time only one login may be maintained. It may occur also if a client application holding the same user exited previously without logging out properly (for example, because of a crash). An identical user has already logged in. (Under NEX, this error does not occur, because the later login is given priority.)

EncryptionFailure 

Data encryption failed.

Encryption error.

InvalidPID 

The operation specified or accessed an invalid Principal ID.

Invalid principal ID.

MaxConnectionsReached 

Reached the maximum number of connections.

Reached the maximum number of connections allowed by the NGS.

InvalidGID 

The operation specified or accessed an invalid GatheringID.

Invalid gathering IDs, including those for gatherings that do not exist.

InvalidControlScriptID 

The Control Script ID that was specified is not a user control ID but the ControlScript to be scheduled is a user ControlScript, or the Control Script ID that was specified is not a system control script ID but the ControlScript to be scheduled is a system ControlScript.

Invalid thread ID.

InvalidOperationInLiveEnvironment 

The operation is not allowed in a Live environment.

Attempted to execute a disallowed function.

DuplicateEntry 

The operation would have caused a duplicate to be created, which is an error: operation aborted.

Attempted to register the same entry more than once.

ControlScriptFailure 

An error occured while processing a control script: missing file, missing ControlScript class or syntax error in script.

Failed to initialize the server. (Does not occur on clients.)

ClassNotFound 

The Python class was not found.

Client and server protocols do not match.

SessionVoid 

The session gathering to join was no longer available.

Nonexistent gathering.

DDLMismatch 

The server encountered an unrecognized or mismatched user-defined protocol or class.

Verify that the latest BPT files are uploaded to the server and loaded from the UserConfiguration.py and that clients compiled with older incompatible versions of the DDL are not connecting to the server. The client and server protocols do not match.

InvalidConfiguration 

The server encountered an error.

Verify that the server is well-configured. Game server settings are incomplete. This problem does not occur in the product environment.

SessionFull 

The maximum number of participants allowed for the gathering has been reached.

InvalidGatheringPassword 

Invalid gathering password.

WithoutParticipationPeriod 

Not within the participation period.

PersistentGatheringCreationMax 

Reached the upper limit for persistent gathering registration.

PersistentGatheringParticipationMax 

Reached the upper limit for persistent gathering participation.

DeniedByParticipants 

Denied by participant (because of registration on the blocked list).

ParticipantInBlockList 

Participants include a user registered on the local system's blocked list.

GameServerMaintenance 

Specifies that game server maintenance will begin.

OutOfRatingRange 

A rating value out of the range for a rating match was specified.

ConnectionDisconnected 

Disconnected from the game server.

InvalidOperation 

Attempted an invalid operation.

NotParticipatedGathering 

The specified user has not joined the gathering.

MatchmakeSessionUserPasswordUnmatch 

The matchmaking session user password does not match.

MatchmakeSessionSystemPasswordUnmatch 

The matchmaking session system password does not match.

UserIsOffline 

The specified user is offline.

AlreadyParticipatedGathering 

Already joined the gathering.

PermissionDenied 

Attempted an operation without permission.

NotFriend 

The specified user is not a friend.

SessionClosed 

The gathering is closed to new participants.

DatabaseTemporarilyUnavailable 

The database is temporarily inaccessible.

InvalidUniqueId 

The NEX unique ID is invalid.

MatchmakingWithdrawn 

The matchmaking request was withdrawn.

LimitExceeded 

Limit exceeded.

AccountTemporarilyDisabled 

The account is temporarily unavailable.

PartiallyServiceClosed 

The service is partially down and cannot be used.

ConnectionDisconnectedForConcurrentLogin 

Disconnected from the game server because a user with the same principal ID logged in.
