static void nn::nex::GlobalVariables::ReleaseInstance ( )
static

Releases the global variables used in the NEX library.

Not recommended:
This function has been preserved for backward compatibility. Applications do not need to use this.

You must call this function as many times as you called AcquireInstance().

static int32_t nn::nex::GlobalVariables::GetCount ( )
static

Gets the number of calls that must be made to the ReleaseInstance() function when the library is released.

Not recommended:
This function has been preserved for backward compatibility. Applications do not need to use this.

If the AcquireInstance() function has been called x number of times, the ReleaseInstance() function must be called the same number of times. This function returns the value that results from subtracting the number of calls to ReleaseInstance() from the number of calls to AcquireInstance(). It can be used after the instance of the NEX Core object is released. Call ReleaseInstance() the same number of times as the return value of this function to release the global variables. This function may return an invalid value if it is called before the NEX Core object has been released. In the debug build, the processing stops on an assertion failure.

Returns
Returns the number of calls to the AcquireInstance() function minus the number of calls to the ReleaseInstance() function.
