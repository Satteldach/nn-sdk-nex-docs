Detailed Description

Root class for all client features that communicate with a game server.

Constructor & Destructor Documentation

nn::nex::ServiceClient::ServiceClient ( uint32_t  uiServiceID)
Parameters
uiServiceIDThe service ID of the service.
Note:
Only classes that inherit from the ServiceClient object should be instantiated and not the ServiceClient object itself. ServiceClient objects should only be created after a client has logged in to the lobby (via RendezVous::Login). Refer to the Integration page for further details as to the correct order of calls.
virtual nn::nex::ServiceClient::~ServiceClient ( )
virtual

Only classes that inherit from the ServiceClient object should be destroyed and not the ServiceClient object itself.

ServiceClient objects should be destroyed before the client logs out of the lobby (via RendezVous::Logout). Refer to the Integration page for further details as to the correct order of calls.

virtual bool nn::nex::ServiceClient::Bind ( Credentials *  pCredentials)
virtual

Registers a certificate for using this service.

Sets a certificate for using this service. A certificate must be set before using this feature. After the successful asynchronous processing of the NgsFacade::Login() function, specify the certificate that was obtained by the NgsFacade::GetCredentials() function. After setting a certificate with Bind(), you can call Bind() again to replace it.

Parameters
[in]pCredentialsA certificate for accessing the service.


Return Values

true: Success. Always succeeds if pCredentials is not NULL.

false: pCredentials was NULL.

virtual bool nn::nex::ServiceClient::Unbind ( )
virtual

Unbinds a certificate.

Removes the certificate set by the Bind() function. You can call this function even if you have not called Bind(). Processing equivalent to Unbind() occur automatically when destroying this object. There is no need to explicitly call Unbind().


Return Values

true: The certificate was removed.

false: No-op because Bind() was never called.

Credentials* nn::nex::ServiceClient::GetCredentials ( ) const

Gets the Credentials object bound by the Bind() function.

Return Values
Returns the Credentials object that was bound using the Bind() function. Returns NULL if nothing has been bound using the Bind() function.
