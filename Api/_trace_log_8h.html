Outputs a log using a printf-like interface.

Outputs a log using a printf-like interface. Strings are output only when the TRACE_FLAG supplied to TraceLog is enabled. When tracing is disabled, both the function call and either of the function calls with arguments is destroyed.

Note:
This macro is disabled in the Development and Release builds.
