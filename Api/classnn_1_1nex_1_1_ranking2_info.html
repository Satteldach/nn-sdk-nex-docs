uint32_t nn::nex::Ranking2Info::GetNumRankedIn ( ) const

Gets the total number of scores (how many scores were registered) that have been registered in the target category.

The obtained value is not equal to the length of the list of retrieved ranking data. The value that is obtained is not affected by the mode that was specified to get the rankings (nn::nex::Ranking2Mode).

Return Values
The total number of scores (how many scores were registered) that have been registered in the category.
int32_t nn::nex::Ranking2Info::GetSeason ( ) const

Gets the season.

Returns
Returns the season number. Starts from 0. The maximum season number is 0x7FFFFFFF. If the ranking is obtained for a future season that has not yet been created and has been specified by mistake, the value might be a negative value.
