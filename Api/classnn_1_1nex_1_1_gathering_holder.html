Detailed Description

Gathering holder class.

The Gathering class, and its derived classes (MatchmakeSession and PersistentGathering), are used to send and receive data to and from the game server. A pointer to the Gathering class object is held internally, and when an assignment or a destructor is called, the destructor for that object is also called.
