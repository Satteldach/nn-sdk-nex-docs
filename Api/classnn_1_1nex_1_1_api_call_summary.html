const DateTime& nn::nex::ApiCallSummary::GetCallStartTime ( ) const

Gets the time of the first function call that exceeds the standard call frequency.

Gets the time of the first function call in a series of calls that exceed the standard call frequency stipulated for the function in the guidelines. If the standard call frequency is not exceeded, returns the time of the first call of the location that is called the most.

Returns
The time of the first function call that exceeds the standard call frequency.
uint32_t nn::nex::ApiCallSummary::GetCount ( ) const

Gets the number of times the API was called when the calls exceed the guidelines.

Returns the number of times a function is called in succession if the call frequency exceeds the norm stipulated in the guidelines. If the call frequency norm is not exceeded, this function returns the number of calls in the location where the API was called the most.

Returns
The number of function calls when the standard value is exceeded.
