uint16_t nn::nex::Ranking2CategorySetting::GetResetMonth ( ) const

Gets the month for periodic resets.

Returns
Returns a 12-bit binary value, where each bit represents one month. The lowest bit is January, the next bit is February, and so on. UTC. Periodic resets are performed in the months corresponding to the bits that are set to 1.
