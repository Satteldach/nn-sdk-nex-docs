Detailed Description

Represents parameters for downloading data.

It specifies a target to download by specifying either a data ID or a persistence target.

This class is the same as the DataStoreGetParam class.

void nn::nex::DataStorePrepareGetParam::SetDataId ( uint64_t  dataId_)

Sets the data ID.

This function specifies the data ID of the data to get. If you set this parameter, do not set the persistence target (principal ID and persistence slot ID) with the DataStorePrepareGetParam::SetPersistenceTarget() function.

void nn::nex::DataStorePrepareGetParam::SetAccessPassword ( uint64_t  accessPassword_)

Sets an access password.

Sets an access password to use when working with data to which the user does not have access permissions. Specify the access password received from the owner of the data. If the user has access permissions, the access password is ignored and the data can be accessed at any time. If you specify DataStoreConstants::INVALID_PASSWORD, authentication by using an access password is not performed. If no password is specified with this function, DataStoreConstants::INVALID_PASSWORD is used.
