Detailed Description

The class for storing the parameters that specify the behavior with block lists.

The default settings are MatchmakeBlockListParam::SetUseMyBlockList(true) and MatchmakeBlockListParam::SetUseBlockListByOthers(true).

void nn::nex::MatchmakeBlockListParam::SetUseMyBlockList ( bool  useMyBlockList)

Sets whether to check if there are any users you have registered on your block list.

Specify true to prevent the local station for joining a matchmaking session if there are any participants in the session who have been registered on the local station's block list. Specify false to join the session no matter what. The default value is true.
