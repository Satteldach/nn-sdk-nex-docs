Detailed Description

Measures the time required to execute code.

This class can be used to get the total required time, average time, maximum time, and minimum time required to execute a certain block of code. For example, if you wanted to measure the time spent executing the foo function, you add something like the following code around the foo function:

{
static NAMESPACE_NEX ProfilingUnit s_pu(NEX_T("foo_func"));
NAMESPACE_NEX ProfilingUnit::Scope scoped(s_pu);
foo();
}

After executing this code several times, you can get the time-measurement information registered to the s_pu instance by calling GetTotalTime() or another member function for s_pu.
