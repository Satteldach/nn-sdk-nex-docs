Detailed Description

Data holder class.

The Data class and classes that inherit Data (UserMessage, TextMessage, and BinaryMessage) are used to send and receive data to and from the game server. A pointer to Data class objects is maintained internally. A destructor for the object being maintained is also called when calling for assignment or a destructor.

Constructor & Destructor Documentation

nn::nex::DataHolder::DataHolder ( )

Constructor.

A null pointer is set as the default value.

nn::nex::DataHolder::~DataHolder ( )

Destructor.

Releases the Data class object being maintained. If you are using the Data class object even after destroying DataHolder, make sure that you change the ownership rights of the object by calling Release.
