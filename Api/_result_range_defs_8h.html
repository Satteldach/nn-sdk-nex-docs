#define RESULTRANGE_ANY_OFFSET   0xFFFFFFFFUL

A dummy offset value to reorder the search results randomly.

If you specify this value as the offset for the ResultRange object, the game server randomly reorders the search results and returns results to the client equal in size to the list.
