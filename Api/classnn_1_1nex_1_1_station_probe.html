Detailed Description

A class for storing a device’s address data (StationURL) and round-trip time (RTT) measured during NAT traversal.

Applications do not ordinarily need to create this directly. This is instantiated by the StationProbeList constructor or the StationProbeList::AddStationURL() function.

StationURL& nn::nex::StationProbe::GetPreferredURL ( )

The connection data obtained through NAT traversal.

You can use this after VSocket::ProbeStations() has completed. Call StationURL::GetInetAddress(), InetAddress::GetAddress(), and InetAddress::GetPortNumber() to get an IP address and port number from the StationURL object.

uint32_t nn::nex::StationProbe::GetPingTime ( ) const

Gets the round-trip time (RTT) measured through NAT traversal.

You can use this after VSocket::ProbeStations() has completed. You can also use this function to determine whether NAT traversal has succeeded. This returns Infinite if NAT traversal has failed.


Return Values

Infinite: NAT traversal failed.

Non-Infinite: The round-trip time (in milliseconds) to this device.
