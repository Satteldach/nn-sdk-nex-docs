static uint32_t nn::nex::ErrorCodeConverter::ConvertToNetworkErrorCode ( const qResult &  qresult)
static

Converts a qResult-type value to an error code for debugging.

Converts the qResult-type value returned by the NEX library to a network error code. This function is used for debugging. Use ErrorCodeConverter::ConvertToErrorCodeStruct() for a format that can be passed to the error viewer applet.

Returns 0 for SUCCESS. Returns 23060000 when a result not defined with the NEX library is passed. (It stops with an assertion failure in the Debug build.)

static nn::err::ErrorCode nn::nex::ErrorCodeConverter::ConvertToErrorCodeStruct ( const qResult &  qresult)
static

Converts a qResult-type value to an error code.

Converts the qResult-type value returned by the NEX library to an error code. The converted values can be passed to the Error Viewer applet.

Returns 0 for SUCCESS. Returns 2306-0000 when a result not defined with the NEX library is passed. (It stops with an assertion failure in the Debug build.) This function converts Result values as defined by the NEX library to unique identifying codes, but not all codes must be shown to the user as errors. For more information about the error codes to display, see the API reference and the programming manual.

static nn::err::ErrorCode nn::nex::ErrorCodeConverter::ConvertToErrorCodeStruct ( uint32_t  last)
static

Converts the value obtained by the SystemError::GetLast() function to an error code.

Converts the error value obtained by the SystemError::GetLast() function to an error code. The converted values can be passed to the Error Viewer applet.

2306-0000 is returned if an error value not defined by the NEX library is passed. This function converts SYSTEMERROR_XXX_XXXX constants as defined by the NEX library to unique identifying codes, but not all codes must be shown to the user as errors. For more information about the error codes to display, see the API reference and the programming manual.
