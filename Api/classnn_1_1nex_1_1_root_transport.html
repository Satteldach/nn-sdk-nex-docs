Detailed Description

Used to configure settings for timeout and transport. Sets the timeouts used for connection, disconnection, and NAT traversal, and sets transport tuning parameters.

enum nn::nex::RootTransport::PacketHistoryCount

Statistical type value for the number of packets used for PacketHistoryBundling.

This value is used as an index for the array returned by the GetPacketHistoryBundlingPacketCounts() function and as an argument to the GetPacketHistoryBundlingPacketCount() function.

Enumerators
PACKET_HISTORY_UNBUNDLING_COUNT 

The number of cases for which no bundling is determined.

PACKET_HISTORY_BUNDLING_COUNT_NONE 

The number of cases where there were no packets to be bundled in the queue and bundling could not be performed.

PACKET_HISTORY_BUNDLING_COUNT_ONE_AND_MORE 

The number of cases where at least one packet was bundled.

PACKET_HISTORY_BUNDLING_COUNT_A_HALF_AND_MORE 

The number of cases where at least the number of packets given by one half of SetPacketHistoryBundlingMaxRetransmitPackets were bundled.

PACKET_HISTORY_BUNDLING_COUNT_MAX 

The number of cases where the number of packets specified by SetPacketHistoryBundlingMaxRetransmitPackets were bundled.

PACKET_HISTORY_TOTAL_COUNT 

The total number of packets equal to the sum of PACKET_HISTORY_UNBUNDLING_COUNT + PACKET_HISTORY_BUNDLING_COUNT_NONE + PACKET_HISTORY_BUNDLING_COUNT_ONE_AND_MORE.

static void nn::nex::RootTransport::SetTransportBufferPoolNum ( unsigned int  poolNum)
static

Sets the number of memory pools used for buffers by the transport buffer thread.

The maximum transmission unit, or the maximum size that can be sent for a single network transmission, abbreviated as MTU, is the size of a single memory pool. Memory of size MTU can be allocated for the number of memory pools specified by this function. This memory is allocated when a NEX Core object is created, and released when that Core object is destroyed.

Parameters
[in]poolNumThe number of memory pools. The default value is 64.
