Detailed Description

Manages internal log output for NEX.

Manages internal log output for NEX. By setting EventLog::LogLevel you can control how the NEX log is output. Log output is always disabled in the release build.

enum nn::nex::EventLog::LogLevel

Enumerators indicating the importance of the log.

Enumerators
Debug 

NEX internal debug information.

Info 

Detailed information about NEX internal processing (default).

Warning 

Warning that can be ignored but needs to be fixed.

Error 

Recoverable error that needs to be fixed.

Fatal 

Unrecoverable error.

Always 

Log information that is always output.
