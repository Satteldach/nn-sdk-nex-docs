enum nn::nex::NotificationEvents::NotificationEvents

Enumerated type defining the types of notification events.

Enumerated type defining the types of notification events. Sets the NotificationEvent class object passed to the NotificationEventHandler::ProcessNotiticationEvernt() function.

As a general rule, the issuance of friend notification type notification events (GameNotificationType1 through GameNotificationType8, GameNotificationLogout and UserStatusUpdatedEvent) takes the presence privacy setting into account. However, there are exceptions where this setting cannot be taken into account.

Enumerators
ParticipationEvent 

Event notifying the owner or participant of a gathering when there has been a change to the status of the participants in the gathering (for example, when a participant joins or leaves). The event details (such as its subtype) are defined by ParticipationEvents. Use NotificationEvent::GetParam1() to get the gathering ID where the event occurred, NotificationEvent::GetParam2() to get the principal ID of the clients that joined and left the session, and NotificationEvent::GetStringParam() to get the associated message.

OwnershipChangeEvent 

Event notification to all the participants in a gathering when the owner of the gathering has changed. Use NotificationEvent::GetParam1() to get the gathering ID where the event occurred and NotificationEvent::GetParam2() to get the principal ID of the new owner.

GameNotificationType1 

Event notification to friends who are logged in to the same game server. The application can freely define both the timing of the notification and data in the notification.

GatheringUnregistered 

Event notification to all the participants in a gathering when the gathering has been deleted. Get the gathering ID triggered by the event with the NotificationEvent::GetParam1() function.

HostChangeEvent 

Notify the previous host when changing the host of a gathering. Get the gathering ID triggered by the event with the NotificationEvent::GetParam1() function.

GameNotificationLogout 

Event notification to friends when logging out from the game server, when a game-defined event has been set. In this case, logging out includes non-explicit logouts such as when power is lost.

SubscriptionEvent 

Specifies an event that is dispatched when a subscription occurs.

GameServerMaintenance 

Specifies an event that is dispatched when game server maintenance begins.

MaintenanceAnnouncement 

Specifies an event that is dispatched when a game server maintenance announcement is made. The NotificationEvent::GetParam1() function gets the maintenance start time in Unix Epoch Time. The server maintenance time in UTC can be retrieved using the DateTime::FromUnixEpochTime() function.

RoundStarted 

Event notification to all round participants when the round starts. Use NotificationEvent::GetParam1() to get the round ID.

FirstRoundReportReceived 

Event notification to all round participants when the server receives the first round report. Use NotificationEvent::GetParam1() to get the round ID.

RoundSummarized 

Event notification to all round participants when round summarizing has completed. Use NotificationEvent::GetParam1() to get the round ID.

MatchmakeSessionSystemPasswordSet 

This event notifies all participants of a session when a system password is set for the matchmaking session. Use the NotificationEvent::GetStringParam() function to get the matchmaking session system password.

MatchmakeSessionSystemPasswordClear 

This event notifies all participants of a session when the system password for the matchmaking session is cleared.

AddedToGathering 

Indicates that the local station was added to the gathering. This notice is sent from other users to the user that was added to the gathering by one of the following functions: MatchmakeExtensionClient::AutoMatchmake(), MatchmakeExtensionClient::JoinMatchmakeSession(), or MatchmakeExtensionClient::CreateMatchmakeSession. Get the added gathering ID with the NotificationEvent::GetParam1() function and the principal ID of the added user (that is, the principal ID of the local station) with the NotificationEvent::GetParam2() function. The NotificationEvent::GetStringParam() function gets the join message specified when the user that triggered the event joined the session. The NotificationEvent::GetSource() function can be used to get the principal ID of the user who called the RMC.

UserStatusUpdatedEvent 

The event that is notified when SubscriberClient::UpdateUserStatus() is used to update status.
