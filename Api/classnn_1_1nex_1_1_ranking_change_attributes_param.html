void nn::nex::RankingChangeAttributesParam::SetModificationFlag ( qByte  flag)

Sets the modification flag.

Specifies a flag indicating the locations of the attributes to change. This parameter must always be specified. You can specify multiple values using a bitwise OR of RankingConstants::ModificationFlag.

Parameters
[in]flagReturns the bit flag indicating the locations of the attribute values to modify. A bitwise OR of RankingConstants::ModificationFlag.

void nn::nex::RankingChangeAttributesParam::SetGroup0 ( qByte  group0)

Sets group 0.

Specifies the new group 0 value. This parameter specification is not required. The default value is 0. The group 0 value will not be updated unless the modification flag is set to RankingConstants::MODIFICATION_FLAG_GROUP0.
