bool nn::nex::MatchmakeParam::SetCountryCode ( const String &  countryCode)

Sets the ISO 3166-1 alpha-2 two-letter country code.

Sets the country code to use when the setting is not to use location information with the UseGeoIP function, or when the setting is to use location information but location information cannot be obtained. If location information can be obtained, this country code is not used. If the country code is not set, and the setting is not to use location information with the UseGeoIP function, or the setting is to use location information but location information cannot be obtained, the score for comparing the country codes is evaluated as a default score.

Parameters
[in]countryCodeCountry code.
Returns
Returns whether the string is appropriate for a country code. If the string is not appropriate, the value is not set.
void nn::nex::MatchmakeParam::SetOverrideIpAddress ( const String &  overrideIpAddress)

Sets an IP address for debugging.

Sets an IP address for debugging. Gets location information with GeoIP using this IP address rather than the current IP address. This function can only be used for debugging. When a MatchmakeParam object included in a MatchmakeSession retrieved from the server is used with the MatchmakeExtensionClient::UpdateMatchmakeSession() function, and the IP address for debugging is used, you must use this function to set the IP address for debugging again.

void nn::nex::MatchmakeParam::SetUpdateGeoIp ( bool  updateGeoIp)

Sets whether to update the location information.

Sets whether to update the location information. This function can be used on the MatchmakeParam object of the MatchmakeSession specified in the MatchmakeExtensionClient::UpdateMatchmakeSession() function. If set for updating, the location information is overwritten with that for the local user. If not set either way, the location information is updated by default. If set to not update the location information recorded on the server, you must get the pertinent matchmaking session from the server and use its MatchmakeParam object. If set to use the MatchmakeParam object created on the client and to not update, the location information is deleted.

Parameters
[in]updateGeoIpSpecifies whether to use location information.
