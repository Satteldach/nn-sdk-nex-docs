Detailed Description

Base class for instant messaging receipt handlers.

To handle an instant message receipt event, you must register in the MessagingClient a MessagingNotificationHandler subclass that has implemented the MessagingNotificationHandler::DeliverInstantMessage() function. After a handler is registered, each time a client receives a notification message, the message is sent to the handler and the DeliverInstantMessage callback is called.

Callback function called upon receipt of an instant message.
