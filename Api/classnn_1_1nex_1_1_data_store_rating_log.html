Detailed Description

Represents the ratings log.

Member Function Documentation

bool nn::nex::DataStoreRatingLog::IsRated ( ) const

Determines whether the local host has been rated in the past.


Return Values

true: Has been rated.

false: Has not been rated. The value obtained with the DataStoreRatingLog::GetRatingValue() function is not a valid value.

PrincipalID nn::nex::DataStoreRatingLog::GetPrincipalId ( ) const

Gets the principal ID of the source that gets the ratings log. (Always the principal ID of the local host.)

Returns
Returns its own principal ID.
int32_t nn::nex::DataStoreRatingLog::GetRatingValue ( ) const

Gets the ratings value when the local host has previously been rated.

Use this function after confirming whether ratings were performed previously with the DataStoreRatingLog::IsRated function.

Returns
Returns the rating value. Not a valid value when no ratings were made in the past.
const DateTime& nn::nex::DataStoreRatingLog::GetLockExpirationTime ( ) const

When the duplicate lock is set, gets the time until the next ratings can be made.

Returns
Returns the time until the duplicate lock is removed. When someone has not rated in the past, or when the duplicate lock is not set, the value is DateTime(0).
