unsigned int nn::nex::Ranking2ChartInfo::GetSamplingRate ( ) const

Gets the sampling rate.

The actual sampling rate is (1/ (1 << GetSamplingRate() ), where population_size * (1/ (1 << GetSamplingRate()) samples of data are used for the estimation. A return value of 0 indicates that all scores are sampling data. A return value of 1 indicates that roughly 50% of all scores are sampling data. A return value of 2 indicates that roughly 25% of all scores are sampling data.

Return Values
The pre-bit shift value for the inverse of the sampling rate.
