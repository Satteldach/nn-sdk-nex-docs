Detailed Description

DebugClient provides the following features to support debugging.

  • A feature for keeping records of calls made to the NEX API during communication with the game server
  • A feature for getting those records.
  • A feature for changing the game server settings in ways that improve the efficiency of debugging.

The header file for these features is retained only for the sake of backward compatibility.

Do not use these features from your application. Instead, use the features from NMAS (the web system for managing NEX servers).

Following a future server update sometime after 2022-03-01, an error will be returned indicating failure when these features are used from the application. This update will be applied to all environments (development environments and production environments).

Even before 2022-03-01, the inclusion of these features was prohibited in applications for master ROM submission.

bool nn::nex::DebugClient::EnableApiRecorder ( ProtocolCallContext *  pContext)

Enables the recording of function calls by the server.

Enables the recording of function calls by the server.

The recording of API calls is normally disabled. Enable recording by using the DebugClient::EnableApiRecorder() function. Recording is automatically disabled if more than one hour has passed without any API calls.

Parameters
[in,out]pContextCall information.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

bool nn::nex::DebugClient::DisableApiRecorder ( ProtocolCallContext *  pContext)

Disables the recording of function calls by the server.

Disables the recording of function calls by the server. When the feature is disabled, the log of recorded function calls is entirely deleted.

Note that the recording of function calls is either enabled or disabled for the server overall, so if you call DisableApiRecorder, it affects the other clients that are also using DebugClient.

bool nn::nex::DebugClient::GetApiCalls ( ProtocolCallContext *  pContext,

DateTime  sinceTime = DateTime::Never,

Gets a log of the API calls by the server.

Gets a list that is a log of API calls, based on the specified conditions. The list shows the calls in the order they were made.

For the conditions for the function calls to get, you can specify a call time and the principal ID of the called client.

To get a log of calls made after a specified time, specify a value for sinceTime. Similarly, to get a log of calls made before a specified time, specify a value for untilTime. If you do not want to specify a time frame, pass DateTime::Never as the argument.

To get the log for specific principal IDs, set a list of the principal IDs that you want in principalIds. Provide an empty list for the argument if you do not intend to specify anything.

The following results may be returned as a result of asynchronous operation.

  • QERROR(RendezVous, InvalidConfiguration): The API call log feature has been disabled.

Totals the API calls in the API call log, and determines whether the API call frequency is within the allowable limit.

Totals the API call information that matches the specified conditions, and then calculates the number of API calls and whether that result is within the limits stipulated in the guidelines.

For the conditions for the function calls to get, you can specify a call time and the principal ID of the called client.

To get a log of calls made after a specified time, specify a value for sinceTime. Similarly, to get a log of calls made before a specified time, specify a value for untilTime. If you do not want to specify a time frame, pass DateTime::Never as the argument.

The following results may be returned as a result of asynchronous operation.

bool nn::nex::DebugClient::SetExcludeJoinedMatchmakeSession ( ProtocolCallContext *  pContext,
bool  bAvoidPreviousGathering 
)

Sets whether to exclude matchmaking sessions that the user has previously participated in from the auto-matchmaking target.

Use this function if you want the MatchmakeExtensionClient::AutoMatchmake() function to join the same matchmaking sessions multiple times while you are debugging your application. See the programming manual for the criteria for matchmaking sessions to be excluded from the target. This setting is enabled by default.

This setting is applied to the entire game server.

The following results may be returned as a result of asynchronous operation.

  • QERROR(Core, NotImplemented): This game server does not use the matchmaking feature.
Parameters
[in,out]pContextCall information.
[in]bAvoidPreviousGatheringWhether to exclude matchmaking sessions that the user has previously participated in from the auto-matchmaking target. Whentrue, this setting is enabled and matchmaking sessions are excluded as gatherings to join. (This setting is the default.) When false, this setting is disabled and matchmaking sessions are not excluded as gatherings to join.
