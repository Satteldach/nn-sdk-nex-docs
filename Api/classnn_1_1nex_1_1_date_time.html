Detailed Description

Stores date and time specifications.

The enabled format for dates and times is YYYY-MM-DD HH:MM:SS.

bool nn::nex::DateTime::IsValid ( ) const

Determines whether the set time is valid.

This function does not check the number of days for a specific month, or whether it is a leap year. It only checks whether the date is within a valid range.


Return Values

true: The time is a valid time.

false: The time is not a valid time.

static void nn::nex::DateTime::GetSystemTime ( DateTime &  tDateTime)
static

Gets the current time held by the device. The time zone of the obtained time depends on the platform. nn::time::StandardUserSystemClock::GetCurrentTime() is used for implementation. To get the local time, use DateTime::GetLocalSystemTime().

Parameters
[out]tDateTimeSystem time.
nn::time::PosixTime nn::nex::DateTime::ToPosixTime ( ) const

Gets the configured time converted to a nn::time::PosixTime-type dated object.

The configured value is considered UTC and is not converted into local time. If DateTime::Never has been configured, the function returns nn::time::PosixTime standard time (time elapsed since 1970-01-01 00:00:00).

Returns
Returns the time as a nn::time::PosixTime-type value.
nn::time::CalendarTime nn::nex::DateTime::ToCalendarTime ( ) const

Gets the configured time converted to a nn::time::CalendarTime-type dated object.

If DateTime::Never has been configured, each value in nn::time::CalendarTime is set to 0.

Returns
Returns the time as a nn::time::CalendarTime-type value.
