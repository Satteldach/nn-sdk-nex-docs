Detailed Description

Base class for handling notification events.

To receive notification events, register a NotificationEventHandler with the client process using NgsFacade::RegisterNotificationEventHandler(). To receive all notification events, register this handler before logging in to the game server. If registration is performed after login, the events that were sent between login and registration may not be received. After a handler is registered, each time a client process receives a notification event, the event is sent to the handler and the ProcessNotificationEvent callback is called.
