bool nn::nex::Ranking2Client::PutScore ( ProtocolCallContext *  pContext,
const Ranking2ScoreData &  scoreData,
UniqueId  nexUniqueId = INVALID_UNIQUEID 
)

Registers scores.

Uploads a single score to a single category. This function can only upload scores for the currently logged in user. This function cannot upload scores for other users. If a score outside of the valid range of scores configured for the category is passed to this function, that score is isolated as an invalid score and moved to a location where it will not appear in the rankings.

The following results may be returned as a result of asynchronous operation. Pass errors to the error viewer applet. Errors must be removed during debugging.

  • QERROR(Ranking2, InvalidArgument): A problem occurred when specifying a parameter.
Parameters
[in,out]pContextCall information.
[in]scoreDataScore data.
[in]nexUniqueIdThe NEX unique ID.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

bool nn::nex::Ranking2Client::PutScore ( ProtocolCallContext *  pContext,
const qVector< Ranking2ScoreData > &  scoreDataList,
UniqueId  nexUniqueId = INVALID_UNIQUEID 
)

Registers scores.

Uploads multiple scores to multiple categories. This function can only upload scores for the currently logged in user. This function cannot upload scores for other users. The maximum number of scores that can be uploaded at once is Ranking2Constants::MAX_PUT_MULTI_SCORES. If a score outside of the valid range of scores configured for the category is passed to this function, that score is isolated as an invalid score and moved to a location where it will not appear in the rankings. If the specified list of scores contains both valid scores and invalid scores, the valid scores are uploaded to rankings and the invalid scores are isolated to another location.

The following results may be returned as a result of asynchronous operation. Pass errors to the error viewer applet. Errors must be removed during debugging.

  • QERROR(Ranking2, InvalidArgument): A problem occurred when specifying a parameter.
Parameters
[in,out]pContextCall information.
[in]scoreDataListList of score data.
[in]nexUniqueIdThe NEX unique ID.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

bool nn::nex::Ranking2Client::GetEstimateScoreRank ( ProtocolCallContext *  pContext,
const Ranking2EstimateScoreRankInput &  input,
Ranking2EstimateScoreRankOutput *  pOutput 
)

Estimates the ranking order from the scores. You can get the ranking order using an estimated value even when scores fall below the lowest ranking order.

Scores that fall below the minimum ranking order are estimated and calculated based on sampling data.

When no data exists, pOutput -> rank and pOutput -> length are 0.

The following results may be returned as a result of asynchronous operation. Pass errors to the error viewer applet. Errors must be removed during debugging.

  • QERROR(Ranking2, InvalidArgument): A problem occurred when specifying a parameter.

virtual bool nn::nex::ServiceClient::Bind ( Credentials *  pCredentials)
virtualinherited

Registers a certificate for using this service.

Sets a certificate for using this service. A certificate must be set before using this feature. After asynchronous processing of NgsFacade::Login() succeeds, specify the certificate obtained by using the NgsFacade::GetCredentials() function as an argument. After setting a certificate with Bind(), you can call Bind() again to replace it.

Parameters
[in]pCredentialsA certificate for accessing the service.


Return Values

true: Success. This succeeds as long as pCredentials is not NULL.

false: pCredentials was NULL.

Unregisters a certificate.
