Detailed Description

The MatchmakeExtensionClient base class.

Do not use this class directly. In addition, do not use any API functions other than those listed in the API reference.

bool nn::nex::MatchMakingClient::UnregisterGathering ( ProtocolCallContext *  pContext,
GatheringID  idGathering 
)

Deletes a gathering from the game server.

The gathering with the specified ID is deleted from the game server. Only the gathering owner can execute this function. If asynchronous processing succeeds, a NotificationEvents::GatheringUnregistered event is sent to all participants in the gathering.

The following results may be returned as a result of asynchronous operation. Use the application to handle these results.

  • QERROR(RendezVous, SessionVoid): The gathering does not exist.
  • QERROR(RendezVous, PermissionDenied): The caller is not the owner. Otherwise, attempted to delete the official persistent gathering.
Parameters
[in,out]pContextCall information.
[in]idGatheringID of the gathering to be deleted.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

Gets a StationURL for each of the participants in the specified gathering.

The list of StationURL objects returned by this function is expected to be passed to VSocket::ProbeStations(). A single participant may have more than one StationURL. StationURL objects are stored in the same order that their respective participants joined the gathering.

The following results may be returned as a result of asynchronous operation. These should be handled by your application.

  • QERROR(RendezVous, SessionVoid): The gathering does not exist.

Gets the information on the participants in a gathering.

Gets information about the participants in the gathering with the specified ID. This function gets ParticipantDetails objects with the principal IDs of the participants, the string versions of those principal IDs, and the strings specified for the MatchmakeExtensionClient::CreateMatchmakeSession(), MatchmakeExtensionClient::JoinMatchmakeSession(), MatchmakeExtensionClient::AutoMatchmake(), and EndParticipation() functions.

This function cannot be run for gatherings with a maximum number of participant set to 0 (no limit) or a number exceeding 128.

  • QERROR(Core, InvalidArgument): The maximum number of participants in the specified gathering is either greater than 128 or infinite (0). id was INVALID_GATHERINGID.

bool nn::nex::MatchMakingClient::MigrateGatheringOwnership ( ProtocolCallContext *  pContext,
GatheringID  id,
const qList< PrincipalID > &  lstPotentialOwnersID 
)

Changes the owner of a gathering to another participant.

Changes the owner of the specified gathering to another participant. Only the owner of a gathering can do this. If the owner is changed successfully, NotificationEvents::OwnershipChangeEvent will be notified to all participants in the gathering.

The following results may be returned as a result of asynchronous operation. Use the application to handle these results.

  • QERROR(RendezVous, SessionVoid): The gathering does not exist.
  • QERROR(RendezVous, PermissionDenied): The caller is not the owner.
  • QERROR(RendezVous, NotParticipatedGathering): The lstPotentialOwnersID parameter was set to an empty list, but there are no participants except for the current owner. None of the users specified in lstPotentialOwnersID are participants in the gathering.
  • QERROR(RendezVous, UserIsOffline): The users specified in lstPotentialOwnersID do not exist or are offline.
  • QERROR(Core, InvalidArgument): id was INVALID_GATHERINGID.
Parameters
[in,out]pContextCall information.
[in]idThe gathering ID whose owner is to be changed.
[in]lstPotentialOwnersIDCandidate list for owner transfer. The candidate at the beginning of the list is given priority when selected. If the list is empty, the new owner is automatically selected from participants in the gathering. In such cases, the player that has been participating in the gathering the longest becomes the new owner.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

bool nn::nex::MatchMakingClient::UpdateGatheringOwnership ( ProtocolCallContext *  pContext,
GatheringID  id 
)

Changes the gathering owner to the caller.

Changes the owner of the specified gathering to the caller. The GatheringFlags::ChangeOwnerByOtherHost flag must be set in the flags of the Gathering object. If the owner is changed successfully, NotificationEvents::OwnershipChangeEvent will be notified to all participants in the gathering. This function does not do anything useful if the user who calls it is already the owner.

The following results may be returned as a result of asynchronous operation. Use the application to handle these results.

  • QERROR(RendezVous, SessionVoid): The gathering does not exist.
  • QERROR(RendezVous, PermissionDenied): Not participating in the gathering.
  • QERROR(RendezVous, InvalidOperation): Could not change the owner because the GatheringFlags::ChangeOwnerByOtherHost flag is not set.
  • QERROR(Core, InvalidArgument): id was INVALID_GATHERINGID.
Parameters
[in,out]pContextCall information.
[in]idThe gathering ID whose owner is to be changed.

bool nn::nex::MatchMakingClient::UpdateSessionHost ( ProtocolCallContext *  pContext,
GatheringID  gid,
bool  isMigrateOwner = false

Changes the gathering host.

The host of the specified gathering is changed to the user that called this function. This function can only be called by gathering participants. If the options are configured such that the GatheringFlags::ChangeOwnerByOtherHost flag is set in flags of the Gathering object, the owner can be changed at the same time. If the owner is changed, NotificationEvents::OwnershipChangeEvent will be notified to all participants in the gathering.

The following results may be returned as a result of asynchronous operation. Use the application to handle these results.

  • QERROR(RendezVous, SessionVoid): The gathering does not exist.
  • QERROR(RendezVous, PermissionDenied): Not participating in the gathering.
  • QERROR(RendezVous, InvalidOperation): Although true was specified for isMigrateOwner, the GatheringFlags::ChangeOwnerByOtherHost flag has not been set, so the owner could not be changed.
Parameters
[in,out]pContextCall information.
[in]gidID of the gathering to change.
[in]isMigrateOwnerSpecifies whether to change the gathering owner to the caller, at the same time.

uint32_t  gatheringID 
)
static

This function is for the callback that is invoked when host migration occurs.

This function is for the callback that is invoked when the local device becomes the parent in a P2P session where the host migration extension is used. UpdateSessionHost() is called automatically within the function, and the game server is notified about the change in host. It also changes the gathering owner to the local user. The GatheringFlags::ChangeOwnerByOtherHost flag must be set in the flags of the target gathering.

Parameters
[in]pMatchMakingClientPointer to MatchMakingClientClient.
[in]gatheringIDID of the gathering to change.


Return Values

true: Successfully started asynchronous processing.

false: pMatchMakingClient was NULL.

Gets the StationURL of the gathering’s host.

Gets the StationURL of the gathering’s host. This function can only be called by gathering participants. Pass the list of URLs obtained with this function (unmodified) to Session::JoinSession() and VSocket::ProbeStations().

  • QERROR(RendezVous, PermissionDenied): Not participating in the gathering.
  • QERROR(Core, InvalidArgument): gid was INVALID_GATHERINGID.
