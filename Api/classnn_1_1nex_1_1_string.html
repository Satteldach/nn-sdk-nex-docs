Detailed Description

Core string type used by NEX.

This class defines the basic string functionality.

The NintendoSDK-NEX supports UTF-8 within the UCS-2 scope. The wchar_t and char16_t types only work within the UCS-2 scope. They do not support surrogate pairs.

template<typename CharT >
LiteralStringHolder<CharT> nn::nex::String::GetLiteralStringAs ( ) const

Gets a string of the specified template type.

By calling String::LiteralStringHolder<CharT>::CStr() after this function, you can get the internal value as an arbitrary string type. Use this when you want to get a string of any type other than qChar (the type returned by String::CStr()). For example, you can call obj.GetLiteralStringAs<char>.CStr() to pass a string to a function that takes a const char* argument. You can specify a string type like char, char16_t, or wchar_t as the template argument.

Returns
An object with a string of the specified template type. Call String::LiteralStringHolder<CharT>::CStr() after this to get the string type.

Converts the entered binary data into a base64 format type qChar string.

If NULL is specified for szADest, the function returns the required size of szADest for conversion without actually converting. The required size includes the space needed for the terminating null character.

Parameters
[in]pbSrcPointer to the input data.
[in]uiSrcLengthSize of the input data.
[out]szADestPointer to the destination buffer for the base64 string. If conversion succeeds, a terminating null character is added to the end of the string.
[in]uiDestLengthThe size of the buffer indicated by szADest, including a terminating null character.
Returns
Returns whether conversion succeeded. If successful, the function returns the length of the post-conversion string.
Return Values

-1: Conversion failed. (The output buffer is not big enough.)

Any other value: The post-conversion string length.
