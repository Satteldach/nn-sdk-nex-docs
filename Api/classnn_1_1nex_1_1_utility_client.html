The unique ID is stored in the save region. Only call this function if it is not saved there.

bool nn::nex::UtilityClient::AssociateNexUniqueIdWithMyPrincipalId ( ProtocolCallContext *  pContext,
const UniqueIdInfo &  uniqueIdInfo 
)

Associates a NEX unique ID with the local user's principal ID.

Registers the NEX unique ID specified in uniqueIdInfo as the primary associated NEX unique ID and deletes any other associations. If INVALID_UNIQUEID is specified as the NEX unique ID, all associations are deleted. If you specify a NEX unique ID that is already associated with a different user, the other user must be offline.

The following results may be returned as a result of asynchronous operation. Pass errors to the error viewer applet. Errors must be removed during debugging.

  • QERROR(RendezVous, DuplicateEntry): Specified a NEX unique ID that is already associated with another person who is online.
  • QERROR(Rendezvous, InvalidPassword): Invalid password.
  • QERROR(Rendezvous, InvalidUniqueId): The NEX unique ID is invalid.
Parameters
[in,out]pContextCall information.
[in]uniqueIdInfoNEX unique ID and password to associate.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

bool nn::nex::UtilityClient::AssociateNexUniqueIdWithMyPrincipalId ( ProtocolCallContext *  pContext,
const qVector< UniqueIdInfo > &  uniqueIdInfo 
)

Associates multiple NEX unique IDs with the local user's principal ID.

If an empty list is specified for uniqueIdInfo, all associations are deleted. The first element in the uniqueIdInfo list is the primary associated NEX unique ID. If you specify a NEX unique ID that is already associated with a different user, the other user must be offline.

The following results may be returned as a result of asynchronous operation. Pass errors to the error viewer applet. Errors must be removed during debugging.

  • QERROR(RendezVous, DuplicateEntry): Specified a NEX unique ID that is already associated with another person who is online.
  • QERROR(Rendezvous, InvalidPassword): Invalid password.
  • QERROR(Rendezvous, InvalidUniqueId): The NEX unique ID is invalid.

virtual bool nn::nex::ServiceClient::Bind ( Credentials *  pCredentials)
virtualinherited

Registers a certificate for using this service.

Sets a certificate for using this service. A certificate must be set before using this feature. After asynchronous processing of NgsFacade::Login() succeeds, specify the certificate obtained using the NgsFacade::GetCredentials() function as an argument. After setting a certificate with Bind(), you can call Bind() again to replace it.

Parameters
[in]pCredentialsA certificate for accessing the service.


Return Values

true: Success. This succeeds as long as pCredentials is not NULL.

false: pCredentials was NULL.

virtual bool nn::nex::ServiceClient::Unbind ( )
virtualinherited

Unregisters a certificate.

Removes the certificate set by the Bind() function. You can call this function even if you have not called Bind(). Processing equivalent to Unbind() occur automatically when destroying this object. There is no need to explicitly call Unbind().


Return Values

true: The certificate was removed.

false: No-op because Bind() was never called.
