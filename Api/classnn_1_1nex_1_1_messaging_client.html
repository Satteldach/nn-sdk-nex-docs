bool nn::nex::MessagingClient::SendInstant ( ProtocolCallContext *  pContext,
PrincipalID  pid,
const UserMessageDataHolder &  oUserMessage 
)

Sends an instant message.

Reliable communication is used to send instant messages through the game server to the specified users. The asynchronous process returns success when the instant message reaches the game server. For this reason, it is not known if the message has arrived at the recipient from the results of the asynchronous results. Messages that reach the game server are guaranteed to reach the recipient as long as the recipient is not disconnected from the game server.

Parameters
[in]pContextCall information.
[in]pidPrincipal ID of the recipient.
[in]oUserMessageMessage data.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

GatheringID  gid,
const UserMessageDataHolder &  oUserMessage

Sends an instant message to all participants in a gathering.

Reliable communication is used to send instant messages through the game server to all the participants of the specified gathering. The asynchronous process returns success when the instant message reaches the game server. For this reason, it is not known if the message has arrived at the recipient from the results of the asynchronous results. Messages that reach the game server are guaranteed to reach the recipient as long as the recipient is not disconnected from the game server.

When using this function on a persistent gathering, the maximum number of participants for that persistent gathering must be set to be no more than PERSISTENT_GATHERING_CHAT_PARTICIPANTS_MAX.

[in]gidGathering ID of the recipient.

Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

Registers a message handler.

Registers a message handler. Once a handler is registered, each time a client receives a notification message, the message is sent to the handler and the MessagingNotificationHandler::DeliverInstantMessage() callback is called.

virtual bool nn::nex::ServiceClient::Bind ( Credentials *  pCredentials)
virtualinherited

Registers a certificate for using this service.

Sets a certificate for using this service. A certificate must be set before using this feature. After asynchronous processing of NgsFacade::Login() succeeds, specify the certificate obtained by using the NgsFacade::GetCredentials() function as an argument. After setting a certificate with Bind(), you can call Bind() again to replace it.

Parameters
[in]pCredentialsCertificate for accessing the service.


Return Values

true: Success. This succeeds as long as pCredentials is not NULL.

false: pCredentials was NULL.

virtual bool nn::nex::ServiceClient::Unbind ( )
virtualinherited

Unbinds a certificate.

Removes the certificate set by the Bind() function. You can call this function even if you have not called Bind(). Processing equivalent to Unbind() occur automatically when destroying this object. There is no need to explicitly call Unbind().


Return Values

true: The certificate was removed.

false: No-op because Bind() was never called.
