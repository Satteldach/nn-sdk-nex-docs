#define NEX_NNRESULT (   FACILITY,
  RETURNCODE 
)    NAMESPACE_NEX Result##FACILITY##RETURNCODE

The error class name derived from nn::Result is generated from the facility and success enumerator.

Generates a class name by concatenating nn::nex::Result, the name of the facility, and the return code.

For example, NEX_NNRESULT(Core, OperationAborted)::Includes(result) is replaced with nn::nex::ResultCoreOperationAborted.

Parameters
[in]FACILITYEnumerator defined in qResultFacility
[in]RETURNCODEFacility name and enumerator defined in SuccessCode.
