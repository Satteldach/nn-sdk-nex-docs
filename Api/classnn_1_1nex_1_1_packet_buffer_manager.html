Detailed Description

Packet buffer memory management class for P2P communication.

Within NEX memory allocation, the packet buffer manager performs memory management for P2P communication.

The packet buffer manager is a feature that allocates a dedicated memory pool (the packet buffer pool) as a batch process before starting P2P communication, and then allocates memory from that packet buffer pool according to packet buffer memory allocation requests.

Memory for the packet buffer pool is allocated using the same method as other NEX objects.

Because packet buffer pools are allocated with a pre-determined size limit, the entire NEX memory could be prevented from being depleted by memory consumption when sending or receiving a large packet.

The packet buffers used with the following communications are not managed with the packet buffer manager but have the same memory management as other NEX objects.

  • Communication with the server
  • Sending and receiving data in excess of the maximum size that the packet buffer manager can allocate (1364 bytes)

The packet buffer pool is allocated before starting P2P communication and is deallocated when P2P communication stops. Specifically, it is allocated the moment the ConnectivityManager::StartNATSession() or VSocket::Open() function is called, and deallocated when the ConnectivityManager::StopNATSession() or VSocket::Close() function is called.

The packet buffer pool is managed by using multiple unit heaps and is used to allocate objects used for managing packets attached to payloads that are not packet payloads. For the payload unit heap, the unit size and number of memory blocks can be customized on the application side. Customize according to the application communication data size.

Packet buffer allocation attempts to allocate memory from the unit heap with the smallest unit size and uses the first unit heap that can be allocated. If allocation is not possible even with the largest unit heap, the packet buffer pool is depleted.

static size_t nn::nex::PacketBufferManager::GetRequiredMemorySize ( const qVector< UnitHeapParam > &  param)
static

Gets the size of the required packet buffer pool based on the unit heap structure information for the passed payload.

The returned pool size is the total of the unit heap for the payload that is allocated based on the passed unit heap structural information for the payload and the unit heap for the packet management object that is automatically allocated in NEX.

If the passed unit heap structural information meets the following conditions, it is considered illegal and 0 is returned.

  • The unit size is either 0 or larger than 1364.
  • The unit size is not a multiple of 4.
  • The number of memory blocks is zero.
  • The array size is 0.
  • The unit size does not have 1364 elements.
Parameters
[in]paramThe structural information for the unit heap for the payload.
Returns
Returns the size of the memory pool. Returns 0 if the unit heap structural information is illegal.
static bool nn::nex::PacketBufferManager::GetSimpleUnitHeapParam ( size_t  poolSize,
size_t  avgSendSize,
qVector< UnitHeapParam > &  param 
)
static

Calculates and returns the simple structure for the unit heap based on the packet buffer pool size and the average send data size.

Simple structures are calculated to fit in a packet buffer pool for which the memory totals for the unit heaps for the payload and for the packet management objects were specified. Half of the memory used by the unit heap for payloads is allocated as a unit heap the size of the average send data, and the remaining half is allocated as an unit heap of the maximum size (1364). Note that the unit size takes the header attached inside NEX, and the average send data send size is increased by 80 and is revised to a value that is a multiple of 4.

Because only packet buffers of 1364 bytes or less are allocated by the packet buffer pool, specify an average send data size that excludes send data that exceeds 1364 bytes.

Perform tuning matching the application based on the structure obtained with this function. The pool size must be set to 64 bytes or higher.

Parameters
[in]poolSizeThe size of the packet buffer pool.
[in]avgSendSizeAverage size of the data sent by the application.
[out]paramThe structural information for the unit heap for the payload.
Return Values

true: Unit heap structure calculation succeeded.

false: The average send data size is 0 or exceeds 1364, or the pool size is too small.

static bool nn::nex::PacketBufferManager::SetUnitHeapParam ( const qVector< UnitHeapParam > &  param)
static

Sets the structural information for the unit heap for the payload used by the packet buffer manager.

Cannot be set when the packet buffer manager is already running. Use the IsActive() function to find out if it is running.

Under the following conditions, an assertion error occurs as illegal information.

  • The unit size is either 0 or larger than 1364.
  • The unit size is not a multiple of 4.
  • The number of memory blocks is zero.
  • The array size is 0.
  • The unit size does not have 1364 elements.

The set values are maintained until NEX terminates.

Parameters
[in]paramThe structural information for the unit heap for the payload.
Return Values

true: Successfully set.

false: Setting failed.

See also
IsActive(), GetUnitHeapParam()
static void nn::nex::PacketBufferManager::GetUnitHeapParam ( qVector< UnitHeapParam > &  param)
static

Gets the structural information of the unit heap for the payload used by the packet buffer manager. If not set with the SetUnitHeapParam() function, returns the structural information used by default.

The default packet buffer pool uses a unit heap with a unit size of 1364 bytes for the payload and a 300 kilobyte region, including a unit heap for the packet management object.

Parameters
[out]paramThe structural information for each unit heap for the payload.

static bool nn::nex::PacketBufferManager::EnablePacketBufferPool ( bool  bEnable)
static

Sets whether to use the packet buffer pool. The default is true. When set to false, the packet buffer is allocated by the default memory manager. This value cannot be changed when the packet buffer manager is running. The configured value is destroyed when the NEX library shuts down.
