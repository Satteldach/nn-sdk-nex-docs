Detailed Description

Class for indicating parameters that are comparison targets when changing metadata with compare and swap.

Constructor & Destructor Documentation

nn::nex::DataStoreChangeMetaCompareParam::DataStoreChangeMetaCompareParam ( )

Constructor.

Generated with the settings that do not perform compare and swap. To perform compare and swap, you must set the value of the flag that is the comparison target.

nn::nex::DataStoreChangeMetaCompareParam::DataStoreChangeMetaCompareParam ( uint32_t  comparisonFlag,
const DataStoreMetaInfo &  metaInfo 
)

Constructor.

References a value specified by the flag from the metadata and generates with the settings that are the comparison target.

Parameters
[in]comparisonFlagBit flag to set the reference value. A bitwise OR of DataStoreConstants::ComparisonFlag. Specify DataStoreConstants::COMPARISON_FLAG_ALL when referencing all.
[in]metaInfoMetadata that is the reference source.

Sets tags.

This function specifies tags to be added as metadata to the data being uploaded. Empty string tags cannot be specified. If tags have already been set, they are deleted and overwritten by the tags specified by this function. This parameter specification is not required. The default is to leave this empty.
