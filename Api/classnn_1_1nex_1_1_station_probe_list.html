Detailed Description

A class that encapsulates a list of StationProbe objects.

This is used during NAT traversal in VSocket::ProbeStations(). This maintains information on the devices (StationProbe objects) for which NAT traversal is used. A StationProbe object contains detailed NAT traversal result data that can be accessed through an iterator like StationProbeList::begin() after VSocket::ProbeStations() has completed.

Constructor & Destructor Documentation

nn::nex::StationProbeList::StationProbeList ( const qList< StationURL > &  reflstStationURL)

Constructor.

The list of StationURL objects given as an argument must be retrieved from the game server with a function like MatchMakingClient::GetSessionURLs(), MatchMakingClient::GetParticipantsURLs(), or MatchmakeExtensionClient::BrowseMatchmakeSession(). These functions usually return more than one StationURL for each device. The specified list of StationURL objects is automatically grouped by device within this constructor and then collected into a StationProbe. Calling StationProbeList::size() on the generated object will return the number of devices.

Parameters
[in]reflstStationURLA list of StationURL objects to maintain internally for NAT traversal.
