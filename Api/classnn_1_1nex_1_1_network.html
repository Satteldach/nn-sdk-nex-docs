static void nn::nex::Network::SetP2PDataPacketDefaultSignatureKey ( const qByte *  pKeyData,
size_t  uiKeyLen 
)
static

Sets the key data to use when computing a default signature for peer-to-peer communications.

By default, data is checked using signatures in peer-to-peer communications by the NEX library. By calling this function, signatures will be calculated using the key data set by the application; this results in slightly more secure communications. This function is intended to be used for local communication. Use SetP2PDataPacketSessionSignatureKey() for communication over the Internet.

You can set a key length between MIN_P2P_DEFAULT_SIGNATURE_KEY_LEN and MAX_P2P_DEFAULT_SIGNATURE_KEY_LEN.

Run this function before creating NEX Core objects.

Parameters
[in]pKeyDataPointer indicating the start of the key data.
[in]uiKeyLenThe key data length (in bytes). If you set this to 0, the default key data will be used.
void nn::nex::Network::SetP2PDataPacketSessionSignatureKey ( const qVector< qByte > &  sessionKey)

Sets the key to use when computing a signature for each peer-to-peer communication session.

Sets the peer-to-peer signing key that can be obtained with the MatchmakeSession::GetSessionKey(), MatchmakeExtensionClient::CreateMatchmakeSession(), or MatchmakeExtensionClient::JoinMatchmakeSession() functions. For more information about how to get the key with the MatchmakeSession::GetSessionKey() function, see the security chapter in the manual. A key can be set by calling the Network::GetInstance() function and then the SetP2PDataPacketSessionSignatureKey() function.

When set, this key is used instead of the key set with the Network::SetP2PDataPacketDefaultSignatureKey() function. A key with a length between MIN_P2P_SIGNATURE_KEY_LEN and MAX_P2P_SIGNATURE_KEY_LEN can be set.

Call this function before the Session::CreateSession() or Session::JoinSession() function. If you do not set a key with this function even though ConnectivityManager::StartNATSession() has been called, the Session::CreateSession() and Session::JoinSession() functions will return an error.

This key is cleared when LANSessionDiscovery is enabled.

[in]sessionKeySession signature key.
