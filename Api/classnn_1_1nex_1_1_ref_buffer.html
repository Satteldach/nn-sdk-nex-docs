Detailed Description

Manages buffer references.

Has a pointer to a buffer, which is shared among RefBuffer objects.
When copying betweenRefBuffer objects, the reference counter for the buffer is incremented. The buffers themselves are not copied.
The destructor for RefBuffer decrements the reference counter for the buffer.
Using the RefBer class makes buffer reference counter operations unnecessary.
