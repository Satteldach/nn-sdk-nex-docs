bool nn::nex::SingleStepJob::Start ( CallContext *  pContext,
bool  deleteOnCompletion = false 
)

Starts the job.

Registers the job with the Scheduler and starts it. The execution state of a registered job is checked every DELAY_TIME_MSEC milliseconds by the SingleStepJob::OnStep() function.

Parameters
[in,out]pContextInformation used to manage the job’s execution state.
[in]deleteOnCompletionSpecifies whether to delete itself when the job completes.


Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified pContext is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it will trigger an assert statement and halt execution on non-release builds.

virtual bool nn::nex::SingleStepJob::OnStep ( qResult *  result)
pure virtual

Checks the state of progress of a job. If you override this method, return true when the job has completed.

This method will be called again after SingleStepJob::DELAY_TIME_MSEC when it returns false. When the job has finished processing and the return value is true, store the results of the job in result.

Parameters
[out]resultProcessing result.
Returns
Returns true if processing is complete, or false if it is still processing.
