void nn::nex::DataStoreRatingInitParam::SetLock ( DataStoreConstants::RatingLockType  lockType_,
int16_t  periodDuration_ = 0,
int8_t  periodHour_ = 0 
)

Sets duplicate locks. This function is not recommended. Use the overloaded function that takes DataStoreRatingLockInitParam as an argument.

Times are taken to be UTC.

Parameters
[in]lockType_The lock type.
[in]periodDuration_The lock period. Specify a lock duration in seconds if lockType is DataStoreConstants::RATING_LOCK_INTERVAL. Specify DataStoreConstants::RatingLockPeriod or an integer greater than 0 if lockType is DataStoreConstants::RATING_LOCK_PERIOD. In the latter case, the integer greater than 0 is the number of days for which to lock the rating. This argument is ignored if lockType is DataStoreConstants::RATING_LOCK_PERMANENT or DataStoreConstants::RATING_LOCK_NONE.
[in]periodHour_Time at which to remove the rating lock. (Valid only when lockType is DataStoreConstants::RATING_LOCK_PERIOD.)
