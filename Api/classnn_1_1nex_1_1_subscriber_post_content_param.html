void nn::nex::SubscriberPostContentParam::SetTopic ( const qVector< String > &  topics_)

Sets multiple topics to post content to.

Specify a topic string with the format r/reserved topic number. Specify an integer in the range from 0 to (NUM_RESERVED_TOPICS - 1) for the reserved topic number. Use the SubscriberUtil::ReservedTopicNumToTopicString() function to create a reserved topic number from a topic string. At least one topic must be specified. The initial value is empty.

Parameters
[in]topics_Post topic.
void nn::nex::SubscriberPostContentParam::SetTopic ( const String &  topic_)

Sets a single topic to post content to.

Shortcut function. Using this overload is more convenient when you only want to set a single topic. Specify a topic string with the format r/reserved topic number. Specify an integer in the range from 0 to (NUM_RESERVED_TOPICS - 1) for the reserved topic number. Use the SubscriberUtil::ReservedTopicNumToTopicString() function to create a reserved topic number from a topic string. The initial value is empty.
