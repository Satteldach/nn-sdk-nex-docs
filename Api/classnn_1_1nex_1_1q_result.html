Detailed Description

Represents the processing results returned by the NEX library.

The results returned by this class are defined by the ErrorCode and SuccesCode definitions in each specific facility. For more information about the individual error codes and success codes that can be returned by a particular facility, see the documentation for that facility.

Do not pass values that can be obtained with the qResult::GetReturnCode() function directly to the error viewer applet. Use qResult::GetNnResult() to pass the available value.

void nn::nex::qResult::Trace ( uint64_t  uiTraceFlags = TRACE_ALWAYS) const

Traces the content of a qResult object.

Outputs a numeric value and a string notation for the return code. The return code that is output is a unique code used to identify the qResult type. It is not an error code.
