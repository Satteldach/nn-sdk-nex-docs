Detailed Description

The class for using Nintendo Switch Online voice chat features.

Constructors and Destructors

virtual nn::nex::SmartDeviceVoiceChatClient::~SmartDeviceVoiceChatClient ( )
virtual

Destructor.

When SmartDeviceVoiceChatClient instances are destroyed, the following processes are performed.

  • Stops heartbeat transmission to the voice chat server when joining a room. When the voice chat server detects a stop in heartbeat, processing to leave the room is performed.
  • When GetAvailability() is processing, this process is canceled.
  • When JoinRoom() is processing, this process is canceled.
  • When LeaveRoom() is processing, this process is canceled.

bool nn::nex::SmartDeviceVoiceChatClient::JoinRoom ( CallContext *  pContext,
const SmartDeviceVoiceChatJoinRoomParam &  param,
SmartDeviceVoiceChatJoinRoomResult *  pResult 
)

Joins a matchmaking voice chat room.

In matchmaking voice chat, the specified session ID is used as a key, and the user joins the room linked to that session. If there is no room associated with the specified session, a room is automatically created, and the user joins that room. After joining a room, the user can voice chat with other users participating in the same room.

Before calling this function, configure the user handle using SetUserHandle().

After calling this function and joining a room, heartbeat transmission to the voice chat server starts in the library.

After joining a room using JoinRoom(), JoinRoom() cannot be called again prior to calling LeaveRoom(). Behavior in such a situation is undefined.

The following results may be returned as a result of asynchronous operation. Have the application handle these results.

  • QERROR(SmartDeviceVoiceChat, UserNotFound): A user not logged in to the Nintendo Switch Online app attempted to start voice chat.
  • QERROR(SmartDeviceVoiceChat, NetworkServiceLicenseRequired): The voice chat server has determined that the user is not a Nintendo Switch Online subscriber.
  • QERROR(SmartDeviceVoiceChat, AccountLibraryError): An account library function called internally returned an error.

For the following errors, you can choose to have the application handle the error, or pass the error to the error viewer applet.

  • QERROR(SmartDeviceVoiceChat, UnderMaintenance): The voice chat server is undergoing maintenance.
  • QERROR(SmartDeviceVoiceChat, ServiceNoLongerAvailable): The Nintendo Switch Online voice chat service has ended.
Parameters
[in]pContextCall information for the join room process.
[in]paramDetailed information, such as the session.
[out]pResultReturns the result of the join room process.


Return Values

true: Successfully started asynchronous processing.

The pContext status specified as false is CallContext::CallInProgress and asynchronous processing cannot start (indicating that other asynchronous processing is in progress), or that the user handle was not correctly configured in SetUserHandle(). Because this is a programming error, an assertion failure occurs and halts execution on non-Release builds.

bool nn::nex::SmartDeviceVoiceChatClient::LeaveRoom ( const SmartDeviceVoiceChatLeaveRoomParam &  param)

Leaves a matchmaking voice chat room.

Calling this function performs processing to leave the room. It also stops the heartbeat that was started by JoinRoom(). Voice chat ends when processing to leave the room is complete.

Before calling this function, configure the user handle using SetUserHandle().

We recommend using this function when leaving a room because error handling does not need to be performed for processing to leave a room. However, because of the following limitations, use the LeaveRoom() function that takes CallContext as an argument.

If a SmartDeviceVoiceChatClient instance is destroyed immediately after calling this function, processing to leave a room may be canceled midway. Even in such cases, because the heartbeat stops, processing to leave the room will be performed when the voice chat server detects a timeout. However, there is a time lag until the voice chat server detects that the heartbeat has stopped, so compared to standard processing to leave a room, more time is required for voice chat to end. To avoid this issue, confirmation that asynchronous processing has completed is required when waiting for processing to leave a room to be complete.

Parameters
[in]paramThe room ID and other details.


Return Values

true: Successfully started asynchronous processing.

false: An appropriate user handle was not set with SetUserHandle(). Because this is a programming error, it causes an assertion failure and halts execution on non-release builds.

bool nn::nex::SmartDeviceVoiceChatClient::LeaveRoom ( CallContext *  pContext,
const SmartDeviceVoiceChatLeaveRoomParam &  param 
)

Leaves a matchmaking voice chat room.

Calling this function performs processing to leave the room. It also stops the heartbeat that was started by JoinRoom(). Voice chat ends when processing to leave the room is complete.

Before calling this function, configure the user handle using SetUserHandle().

You can use this function to check whether asynchronous processing to leave a room has completed. If it is not necessary to confirm that processing is complete, we recommend using LeaveRoom(), which does not take CallContext as an argument.

In addition, even if an error occurs while processing this function, the heartbeat started by JoinRoom() stops, and processing to leave the room is performed when the voice chat server detects a timeout. For this reason, even when this function returns an error, the application does not need to handle the error.

static SmartDeviceVoiceChatShowAppPageResult nn::nex::SmartDeviceVoiceChatClient::ShowAppPage ( const SmartDeviceVoiceChatShowAppPageParam &  param)
static

Displays the web applet for the Nintendo Switch Online application introduction page.

In addition to using this function when presenting the user with ways to perform voice chat, such as via operations in the application UI, you can also use this function when the result of GetAvailability() indicates that the user has never logged in to the Nintendo Switch Online app.

This function blocks processing while the web applet is being displayed. This function terminates when the web applet is closed by a user.

The web applet displayed with this function runs on the same CPU core used by the application. If threads are being used and processes continue while the applet is running, the browser performance can suffer. Note that because this function is a blocking function, depending on the NEX thread mode, you may be logged out from the game server if Scheduler::Dispatch() or Scheduler::DispatchAll() is not called periodically from another thread.

In addition, when a thread-safe memory allocator is configured in the NEX library, this function can be called in parallel with other NEX functions even when using a thread mode that is not thread-safe.

[in]paramParameter for the call to the web applet.

Asynchronously displays the web applet for the Nintendo Switch Online application introduction page.

In addition to using this function when presenting the user with ways to perform voice chat, such as via operations in the application UI, you can also use this function when the result of GetAvailability() indicates that the user has never logged in to the Nintendo Switch Online app.

The web applet is displayed in a separate thread created inside this function. The time until completion of this asynchronous process depends on input from the user.

The following operations are prohibited in relation to this function. If any of these operations are performed, the behavior is undefined.

  • Specifying a web applet display timeout
  • Canceling processing before the return of the web applet display result.
  • Displaying a second instance of the web applet before the return of the web applet display result.

const SmartDeviceVoiceChatChangeVoiceChatChannelParam &  param

Changes the voice chat channel.

Before calling this function, configure the user handle using SetUserHandle().

For matchmaking voice chat, sound data is delivered only to users with matching channels, even if there are other users that have joined the same room. By changing the voice chat channel, it is possible to separate users that have joined the same room into multiple groups, and voice chat with each group.

bool nn::nex::SmartDeviceVoiceChatClient::GetAvailability ( CallContext *  pContext,
bool *  pAvailability 
)

Determines whether the user has ever logged in to the Nintendo Switch Online app.

This function queries the server to determine whether the user specified in SetUserHandle() has ever logged in to the Nintendo Switch Online app. Before calling this function, configure the user handle using SetUserHandle().

To use voice chat, a user must log in to the Nintendo Switch Online app at least once. If a user who has never logged in to the Nintendo Switch Online app calls functions such as JoinRoom(), QERROR(SmartDeviceVoiceChat, UserNotFound) occurs. If this function is called for a user who has never logged in to the Nintendo Switch Online app, instead of QERROR(SmartDeviceVoiceChat, UserNotFound) occurring, pAvailability returns false. Use this function to determine in advance whether the corresponding user can use voice chat.

The following results may be returned as a result of asynchronous operation. Have the application handle these results.

  • QERROR(SmartDeviceVoiceChat, NetworkServiceLicenseRequired): The voice chat server has determined that the user is not a Nintendo Switch Online subscriber.
  • QERROR(SmartDeviceVoiceChat, AccountLibraryError): An account library function called internally returned an error.

For the following errors, you can choose to have the application handle the error, or pass the error to the error viewer applet.

  • QERROR(SmartDeviceVoiceChat, UnderMaintenance): The voice chat server is undergoing maintenance.
  • QERROR(SmartDeviceVoiceChat, ServiceNoLongerAvailable): The Nintendo Switch Online voice chat service has ended.

The settings are used when the function that initiates HTTP communication is called. As a result, you can change the priority for each session by calling this function for each function call that initiates HTTP communication. If this function is not called, the priority becomes SmartDeviceVoiceChatConstants::DEFAULT_HTTP_THREAD_PRIORITY.
