bool nn::nex::ConnectivityManager::StartNATSession ( CallContext *  cc)

Starts a NAT session.

Starts a NAT session and performs the necessary preprocessing for Internet P2P communication.

To use Internet P2P communication, you must call this function before you call VSocket::Open(). Note that the port number used for P2P communication changes every time this function executes.

Domain names are resolved on a separate thread through a DNS server used to detect different NAT types only when this function is called for the first time after an NgsFacade object is created. If the cable on the WAN side of the router is unplugged prior to name resolution, this asynchronous process may take over 30 seconds to complete because it will wait for the name resolution process to time out. Also, because name resolution cannot be canceled, it may take over 30 seconds to shut down the NEX library after StartNATSession() has been called if address resolution has not yet finished. You must create the NATTraversalClient object and bind credentials to that object before calling this function.

To get asynchronous processing results, use the CallContext::GetOutcome function. The following values can be obtained.

  • QSUCCESS(Core, Success): Success.
  • QERROR(Core, InvalidSequence): The NEX library has not been initialized. A NATTraversalClient object has not been created. Or no Credentials have been bound to a NATTraversalClient object. StartNATSession() is already in progress. Bind() has already been called on an existing VSocket object. (The Close function must be called on the VSocket object.)
  • QERROR(Transport, DnsError): DNS timeout.
  • QERROR(Transport, NatCheckError): NAT check error.
Parameters
[in,out]ccCall information.
Return Values

true: Successfully started asynchronous processing.

false: Cannot start asynchronous processing because the status of the specified cc is CallContext::CallInProgress. This value indicates that it is being used in other asynchronous processing. Because this is a programming error, it will trigger an assert statement and halt execution on non-release builds.
