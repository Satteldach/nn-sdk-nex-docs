enum nn::nex::RankingErrorCode::ErrorCode

Ranking error codes.

The following errors represent server problems. Make sure that you display them.

  • QERROR(Ranking, RegistrationError)
  • QERROR(Ranking, Unknown)

The following errors are used for library development, so they never actually occur.

  • QERROR(Ranking, NotImplemented)

The application appropriately handles the rest of the errors, so do not display their error codes or their corresponding messages.
