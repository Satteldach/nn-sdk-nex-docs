Detailed Description

Measures the time that elapses between the calling of the Start() and Stop() functions.

The time elapsed on the local station is measured in milliseconds. Just like a stopwatch, this class can measure elapsed time, excluding the period from when it is stopped to when it is resumed.

bool nn::nex::Chrono::Start ( )

Starts the timer from 0 (using milliseconds).

This function has the same functionality as the start button on a regular stopwatch.


Return Values

true Successfully started.

false Indicates that the timer could not be started because it was not stopped.

See also
Stop()
LargeTimeInterval nn::nex::Chrono::Pause ( )

Pauses the timer.

When paused, the timer can be resumed with the Resume() function as long as it has not been stopped with the Stop() function.


Return Values

0 or higher: Indicates the measured time (and pauses the timer).

–1: Indicates that the timer could not be paused because it has not started.

See also
Resume(), Stop()
bool nn::nex::Chrono::Resume ( )
