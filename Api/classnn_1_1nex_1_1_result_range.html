Detailed Description

Maintains the size and offset of a search results list.

The size is the maximum number of entries to get from among all entries that match the search conditions, and the offset is the starting position of the entries to get.

If you specify RESULTRANGE_ANY_OFFSET for the offset, the game server randomly shuffles all search results and returns to the client the number of entries specified by size. However, with the data store service, up to 1000 of the first search results, as arranged based on the sort target and the sort order, are treated as the target, and a certain number of those entries, as specified by the size parameter, are taken in random order from that and returned to the client. Depending on the sort target and the sort order, the results might not be completely random, so specify search conditions so that the search results contain only the desired data. Use an implementation that avoids including unwanted data in the search results. For example, separate the data types.
