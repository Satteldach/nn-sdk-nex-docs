qByte nn::nex::Ranking2GetParam::GetNumSeasonsToGoBack ( ) const

Gets the number of seasons to go back.

Returns
Returns rankings for a past season. Specify 0 to get rankings for the current season. Specify 1 to get rankings for the most recent past season, 2 to get rankings for the season before that, and so on. The default is 0.
void nn::nex::Ranking2GetParam::SetNumSeasonsToGoBack ( qByte  numSeasonsToGoBack_)

Sets the number of seasons to go back.

Parameters
[in]numSeasonsToGoBack_Specifies which past season to get rankings for. Specify 0 to get rankings for the current season. Specify 1 to get rankings for the most recent past season, 2 to get rankings for the season before that, and so on. The default is 0. This value can be from 0 to the value for the number of past seasons to save configured for the category.
