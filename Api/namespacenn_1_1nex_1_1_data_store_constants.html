Enumeration Type Documentation

enum nn::nex::DataStoreConstants::Permission

Data permissions. Used for both access and update permissions.

Enumerators
PERMISSION_PUBLIC 

Permitted for all principal IDs.

PERMISSION_FRIEND 

Permitted only for the principal IDs of the user and the user's friends.

PERMISSION_SPECIFIED 

Permitted for the specified number of principal IDs.

PERMISSION_PRIVATE 

Permitted for the user only.

PERMISSION_SPECIFIED_FRIEND 

Permitted for the specified number of principal IDs of people who are friends. The server verifies that the principal IDs belong to friends.

enum nn::nex::DataStoreConstants::DataFlag

Upload setting flag.

Enumerators
DATA_FLAG_NONE 

No setting.

DATA_FLAG_NEED_REVIEW 

Indicates that a data review is required by the operator.

DATA_FLAG_PERIOD_FROM_LAST_REFERRED 

Prolong the valid period when accessing and updating data. For more information about this specification, see the Programming Manual.

DATA_FLAG_USE_READ_LOCK 

Cannot be used.

DATA_FLAG_USE_NOTIFICATION_ON_POST 

Notifies the recipient when the DataStoreClient::PostObject() function is executed. The uploaded data can then be downloaded via SpotPass. This feature can only be used on the 3DS and Wii U.

DATA_FLAG_USE_NOTIFICATION_ON_UPDATE 

Notifies the recipient when data that has already been uploaded is updated by the DataStoreClient::UpdateObject() function. The updated data can then be downloaded via SpotPass. This feature can only be used on the Wii U.

DATA_FLAG_NOT_USE_FILESERVER 

Cannot be used.

DATA_FLAG_NEED_COMPLETION 

After the DataStoreClient::PostObject() function completes, do not enable the data on the server until the DataStoreClient::CompleteSuspendedPostObject() function is executed.

enum nn::nex::DataStoreConstants::SearchType

Search type.

Enumerators
SEARCH_TYPE_PUBLIC 

Access permission is DataStoreConstants::PERMISSION_PUBLIC.

SEARCH_TYPE_SEND_FRIEND 

The local host's owner and access rights are DataStoreConstants::PERMISSION_FRIEND.

SEARCH_TYPE_SEND_SPECIFIED 

The local host's owner and access rights are DataStoreConstants::PERMISSION_SPECIFIED.

SEARCH_TYPE_SEND_SPECIFIED_FRIEND 

The local host's owner and access rights are DataStoreConstants::PERMISSION_SPECIFIED_FRIEND.

SEARCH_TYPE_SEND 

The local host's owner and access rights are either DataStoreConstants::PERMISSION_FRIEND, DataStoreConstants::PERMISSION_SPECIFIED, or DataStoreConstants::PERMISSION_SPECIFIED_FRIEND.

SEARCH_TYPE_FRIEND 

Data uploaded by a friend with access permission DataStoreConstants::PERMISSION_FRIEND.

SEARCH_TYPE_RECEIVED_SPECIFIED 

Access permission is DataStoreConstants::PERMISSION_SPECIFIED or DataStoreConstants::PERMISSION_SPECIFIED_FRIEND and data was received by self.

SEARCH_TYPE_RECEIVED 

Access permission is either DataStoreConstants::PERMISSION_SPECIFIED or DataStoreConstants::PERMISSION_SPECIFIED_FRIEND and data was received by self, or data was uploaded by a friend with access permission DataStoreConstants::PERMISSION_FRIEND.

SEARCH_TYPE_PRIVATE 

The local host's owner and access rights are DataStoreConstants::PERMISSION_PRIVATE.

SEARCH_TYPE_OWN 

The local host's owner and DataStoreConstants::DataStatus is DataStoreConstants::DATA_STATUS_NONE.

SEARCH_TYPE_OWN_PENDING 

The local host's owner and DataStoreConstants::DataStatus is DataStoreConstants::DATA_STATUS_PENDING.

SEARCH_TYPE_OWN_REJECTED 

The local host's owner and DataStoreConstants::DataStatus is DataStoreConstants::DATA_STATUS_REJECTED.

SEARCH_TYPE_OWN_ALL 

The local host is the owner and DataStoreConstants::DataStatus is DataStoreConstants::DATA_STATUS_NONE, DataStoreConstants::DATA_STATUS_PENDING, or DataStoreConstants::DATA_STATUS_REJECTED.

enum nn::nex::DataStoreConstants::DataStatus

The status of the data.

Data with DataStoreConstants::DATA_FLAG_NEED_REVIEW specified becomes DataStoreConstants::DATA_STATUS_PENDING after uploading. Data that does not have DataStoreConstants::DATA_FLAG_NEED_REVIEW specified becomes DataStoreConstants::DATA_STATUS_NONE after uploading. With DataStoreConstants::DATA_STATUS_PENDING and DataStoreConstants::DATA_STATUS_REJECTED, only the owner can access or update regardless of the privilege settings. With DataStoreConstants::DATA_STATUS_NONE, access and update permissions depend on the privilege settings.

Enumerators
DATA_STATUS_NONE 

Normal state.

DATA_STATUS_PENDING 

Rating pending.

DATA_STATUS_REJECTED 

Rejected.
