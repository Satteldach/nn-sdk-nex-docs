Detailed Description

Data class that stores conditions used to search for matchmaking sessions.

When search criteria are specified by the AutoMatchmakeParam::SetSearchCriteria() function, sessions that are closed, full, or password-protected are excluded automatically, regardless of the settings.

The settings for whether to exclude sessions that are closed, full, and/or password-protected come into effect when you use the MatchmakeExtensionClient::BrowseMatchmakeSession() function.

Constructor :&amp; Destructor Documentation

nn::nex::MatchmakeSessionSearchCriteria::MatchmakeSessionSearchCriteria ( )

Constructor.

Constructor. The initial state is an invalid search condition. At minimum, the game mode and the matchmaking system type must be specified using the MatchmakeSessionSearchCriteria::SetGameMode() and MatchmakeSessionSearchCriteria::SetMatchmakeSystemType() functions. Matches all matchmaking sessions with the specified game mode and matchmaking system type except for sessions without a host, sessions for which a password has been set, sessions for which participation is locked, and sessions that are full. The search range is RESULTRANGE_ANY_OFFSET.

Constructor.

Constructor. Creates a valid object with the minimum number of required parameters set. Matches all matchmaking sessions with the specified game mode and matchmaking system type except for sessions without a host, sessions for which a password has been set, sessions for which participation is locked, and sessions that are full. The number of items obtained is 20, and the offset is random (RESULTRANGE_ANY_OFFSET).

bool nn::nex::MatchmakeSessionSearchCriteria::SetVacantOnly ( bool  vacantOnly,
uint16_t  participants 
)

Sets whether to exclude full sessions. You can specify the number of vacancies to search for.

Sets whether to exclude full sessions. The default is to exclude. If full sessions are excluded, you can specify the number of vacancies to look for when searching matchmaking sessions.

The MatchmakeExtensionClient::BrowseMatchmakeSession() function then searches for matchmaking sessions with at least as many vacancies at the value you specified for participants.

If specified by AutoMatchmakeParam::SetSearchCriteria(), the search is made for matchmaking sessions with room for the specified number of participants, regardless of this setting.

Parameters
[in]vacantOnlySpecify true when excluding full sessions, and false when not excluding them.
[in]participantsThe number of vacancies. Specify a value of 1 or greater. This value is ignored if you specify false for vacantOnly.


Return Values

true: Successfully set.

false: Failure. This function fails if you specify true for vacantOnly and 0 for participants.
